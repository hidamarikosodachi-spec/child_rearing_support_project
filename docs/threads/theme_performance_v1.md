# Threads テーマ別の反応分析 v1（自社データ 17投稿）

> 「どんな内容が人気か」を**推測ではなく自分の実測**で判断するための整理。
> 更新: `.venv/bin/python scripts/threads_insights.py`

## 前提：外部データは取れない（調査済 2026-09-26）

- Threads 公式 API に**キーワード検索（`/keyword_search`）は存在する**が、`threads_keyword_search` 権限は**審査制**。
  未承認だと自分の投稿しか検索できず、実際に叩くと 500 が返る（確認済）。
- 権限申請には Meta アプリの審査（＝Facebook アカウント必須）が要る。**Instagram 自動投稿と同じ壁**で、見送り中。
- ブラウザでの自動収集は、アカウント停止リスクを負ってまで得る情報ではない（**やらない**）。
- → **自社の17投稿を A/B とみなして読む**のが、いま最も確度の高い方法。

## 読み取れること

### 1. 「親が自分を責めるテーマ」が突出する
上位3つ（叱り方408／動画238／赤ちゃん返り229）に共通するのは、**親が「自分のやり方が悪いのでは」と思っているテーマ**。
下位（公共の場13／きょうだい28／偏食28）は、**困ってはいるが自責になりにくい**もの。
→ **困りごとの大きさではなく、"後ろめたさ" の大きさがリーチを決めている。**

### 2. 告知投稿はリーチが出ない（重要）
診断リリース告知は **views 14**。同時期の通常投稿（80〜238）の**1/10以下**。
宣伝色のある投稿は伸びないと考えるのが妥当（アルゴリズム・読み手の反応の両方）。
→ **告知は単独で投げず、いつもの語り口の投稿の"中"に自然に置く**か、**1返信目のリンクに留める**（現行方式が正しい）。

### 3. 物語（フィクション寄り）は中位で安定
物語②129／⑤104／④73／③42。爆発はしないが、下位にも落ちない。
→ ブランド形成には効くが、リーチ獲得の主役ではない。**痛みテーマ7：物語3** くらいの比率が妥当。

### 4. 返信をもらえたのは「寝かしつけ」だけ（他者返信2）
views 74 と中位なのに、**唯一まとまった他者反応**が出た。
→ views と反応は別物。**夜の孤独と結びつくテーマは、少ないリーチでも人が反応する**可能性。

## 次に試すテーマ（この分析に基づく）

「自責が強い × まだ試していない」で選ぶ。

1. **スマホ・動画を見せてしまう罪悪感**（238 の派生。作業療法士の方の記事も同テーマで反応あり）
2. **怒鳴ってしまったあとの後悔**（叱り方408 の派生・より感情に寄せる）
3. **上の子にきつく当たってしまう**（赤ちゃん返り229 の派生・すでに⑪で80。角度を"自責"に寄せて再挑戦）
4. **保育園に預けることへの後ろめたさ**（未挑戦・自責度が高い）
5. **夜、寝かしつけながら泣きそうになる**（寝かしつけ⑥の反応を取りにいく）

## リンク返信の中止テスト（2026-09-30〜10-14・オーナー提案）

**経緯**: オーナーから「宣伝色が強いと閲覧数が下がるので、note リンクを貼るのをやめないか」と提案。

**実測で確認したこと**: リンク返信の有無で views に差は出ていない。
- リンク返信なし（9/18・9/20）: 104・85 → 平均 **94.5**
- リンク返信あり（告知を除く／9/22・24・26・28）: 80・238・19・53 → 平均 **97.5**
- 明確に落ちたのは**本文が宣伝だった告知投稿（9/25・views 15）**のほう。

**それでも外す理由**: リンク返信は1週間運用して**成果がゼロ**だった（note 新記事 PV 1〜4・診断サイト訪問1件）。
効果が無いなら、リーチを削るリスクが仮にあっても負う意味がない。投稿も読み物として綺麗になる。
※ T101（各SNSを記事への流入導線にする）の一環として私が提案した施策だが、成果が出なかった。読み違い。

**テスト設計**:
- 期間: 2026-09-30 〜 10-14（隔日・約7投稿）
- 比較対象: 直前2週間（リンクあり・告知を除く平均 97.5）
- 判定: 平均 views が明確に上がれば「リンクはリーチを削っていた」＝以後も付けない。
  横ばいなら失うものは無い（宣伝色ゼロのまま継続）。
- **導線はプロフィールのリンク（診断URL）に一本化**する。本文でも返信でも宣伝しない。

## 運用ルール（更新）

- 新テーマは**1本ずつ**投げ、views と他者返信を記録する（いまの「痛みテーマ test⑬⑭…」の連番を継続）。
- **告知は独立投稿にしない**。
- **本文にも返信にもリンクを置かない**（2026-09-30〜のテスト中）。導線はプロフィールのみ。
- 分析は月1回、`threads_insights.py` を回して本ファイルを更新する。
- 指標に**自分の返信（note リンク導線）は数えない**（2026-09-26 に両スクリプトを修正済）。
