# 本気で web だけで広げるなら（CEO 見解 v1）

> オーナー問い（2026-09-29）「本気で web のみで広めるならどうするか」への回答。
> 旧 [[web_only_strategy_v0]]（2026-05-28）を、4ヶ月分の実測で更新する。

## 1. 手元の事実（ここから出発する）

| 経路 | 投下量 | 結果 |
|---|---|---|
| Threads（アルゴリズム配信） | 18投稿・累計 views 約1,770 | **フォロワー0・他者反応2** |
| note 記事 | 12本・4.5ヶ月 | 総PV 238・**フォロワー3** |
| X | 固定ポスト＋プロフィール | 実質ゼロ |
| Instagram | カルーセル1本 | **コメント1（パパ層）** |
| **note 誠実接触** | **5件のコメント** | **実在の読者1人＋関係継続** |
| 診断サイト | 公開・全導線設置 | 訪問1・回答0 |

**読み取れる唯一の法則**:
**表示回数は読者にならない。人に直接届けた分だけ、読者になっている。**
views 1,770 から0人、コメント5件から1人。**接触あたりの効率は 100倍以上違う**。

もうひとつ。**質は足りている**。note のスキ率は約15%（238PV・36スキ）、IG のコメントは
「正しい・間違いではなく方向の違い、という考え方に気持ちが楽になりました」＝**中核の主張そのもの**に返ってきた。
読んだ人には届いている。**届く人数だけが足りていない。**

## 2. 方針：アルゴリズムを諦め、人と検索に賭ける

週3h（オーナー）＋私のフル稼働という条件では、アルゴリズム配信で勝つのに必要な
**投稿量・更新速度・初速の反応**を作れない。フォロワー0の状態で毎日投げ続けても、実測どおり0人のままになる。

だから賭ける先を2つに絞る。

- **人**（今すぐ効く・複利で積む）: note の中で人に会い続ける
- **検索**（半年後に効く・寝ている間に届く）: 自前サイトに悩み別の記事を積む

この2つは**どちらも「フォロワー0でも成立する」**。ここが Threads/X との決定的な違い。

## 3. やること（優先順）

### A. note の中で人に会う量を、上限まで増やす【最優先・今すぐ】
- 誠実接触を **週2バッチ → 毎日2〜3件**（レート上限 他者3件/日）。月60〜80接触。
- 相手選定は実測に沿って「**自責が強いテーマを書いている人**」（叱り方・動画・赤ちゃん返り系）。
- **売り込まない**は不変（[[feedback-note-outreach-no-selling]]）。関係が先、記事は後。
- 見込み: 接触の数%が読者化 → **月2〜5人**。1年で30〜60人。遅いが、**止まらないし減らない**。
- コストは私の時間のみ。オーナーは0分。

### B. note の公式お題・コンテストに毎回応募する【今すぐ・無料】
- note は常時「お題/コンテスト」を開催していて、投稿画面から応募できる（応募＝露出が増える）。
- **note 編集部のピックアップに入ると、一撃で数千PV**。当たれば桁が変わる宝くじだが、**参加費はゼロ**。
- 現状これを一度も使っていない。**公開のたびに、合うお題があれば必ず応募する**運用にする。

### C. 診断を「2人でやるもの」にする【拡散の起点をつくる】
- 診断は本来シェアされる商品なのに、**シェアの動機が無い**（自分の結果を見て終わり）。
- **相性を無料機能として実装する**：結果ページに「パートナーの結果と並べる」導線を置き、
  2人ぶんのタイプを入れると、ぶつかりやすい場面と担当の分け方が出る。
- 効果: ①相手に診断をやらせる動機が生まれる（1人→2人） ②夫婦の会話になる＝人に話す
  ③有料商品A（¥100 全36通り）の**無料の入口**になり、買う理由も強まる。
- **これがいちばん筋の良い拡散装置**。実装は私の作業だけで完結する。

### D. 自前サイトに、悩み別の記事を積む【SEO・半年仕事】
- 「イヤイヤ期 疲れた」「叱りすぎ 後悔」「保育園 行きたくない 朝」等、**検索される言葉**で書く。
- note ではなく**自前サイト（Cloudflare Pages）**に置く。構造・内部リンク・OGP を自分で制御できる。
- **独自ドメインを取る**（年1,000〜1,500円）。`*.pages.dev` は検索で弱い。**これだけは有料化を推奨**。
- 即効性はゼロ。3〜6ヶ月で効き始め、**その後は寝ている間に人が来る**。唯一の複利資産。

### E. 他媒体に書かせてもらう【月1本・打診だけ】
- 育児メディア・自治体の子育て情報サイト・保育士向け媒体へ寄稿を打診。
- 1本載れば数百〜数千リーチ。web完結（メールのみ）で完了する。
- 私が打診文と記事案を書き、オーナーは送信のみ（5分）。

### F. Instagram は維持（週1カルーセル）
- 1投稿でコメント1件＝**反応率は全チャネル中いちばん良い**。しかも**パパ層**が取れた（他では取れていない層）。
- 画像は私が生成、投稿はオーナー5分。**頻度は上げない**（負担増より継続を優先）。

## 4. やめること

- **X**: 4ヶ月動きなし。固定ポストは残すが、運用はしない。
- **Threads の増量**: 隔日は維持するが、本数を増やしても読者にならない（実測）。
  **本文にも返信にもリンクを置かない**（2026-09-30〜のテスト）。
- **告知投稿**: views が通常の1/10（実測）。告知は独立投稿にしない。
- **記事の本数をこれ以上増やすこと**: 週3で供給は足りている。**増やすなら接触と検索に回す。**

## 5. 90日の形（2026-10 〜 2026-12）

| 月 | 主軸 | 到達目標 |
|---|---|---|
| 10月 | A（接触を毎日）＋B（お題応募）＋8タイプ記事の完走 | 接触60件・note フォロワー10人 |
| 11月 | C（相性機能）＋有料A（¥100）＋D の記事を10本 | フォロワー25人・**有料の初売上1件** |
| 12月 | D（SEO記事20本）＋E（寄稿打診3社） | フォロワー50人・検索流入の兆し |

**判定**: 12月末に「フォロワー50人・月間PV 1,000」に届かなければ、**web 集客そのものを再設計する**
（オフライン、B2B、他媒体主軸など、[[monetization_roadmap_v0]] の撤退条件に沿って再決裁）。

## 6. 正直に言っておくこと

- **短期の魔法はない。** ここまで4.5ヶ月で読者3人という数字は、施策の失敗というより
  「**人に届ける行為をしてこなかった**」結果。書く量ではなく、会う量が足りていない。
- **バイラルは狙って起こせない。** note 公式ピックアップも診断のシェアも確率の話。
  だから**確率を上げる打席（B・C）に無料で立ち続ける**設計にする。
- **有料化はまだ主役ではない。** ¥100 が数件売れても事業にはならない。
  11月に出すのは「買う人がいるか」を確かめるためで、収益の柱を立てるのは読者100人を超えてから。
- **唯一お金を使うべきなのは独自ドメイン**（年1,500円）。これは SEO の前提条件。
