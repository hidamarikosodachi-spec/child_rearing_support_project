# カテゴリとタグの設計 v1

> ブログサイトとして「どこに何があるか」が分かる状態にするための分類。
> **カテゴリは増やさない**（迷子になる）。**タグは記事が増えるほど増やす**（検索語に寄せる）。

## カテゴリ（4つ・固定）

| slug | 名前 | 扱うもの |
|---|---|---|
| `kimochi` | 気持ちがしんどい日に | 怒鳴った・イライラ・自己嫌悪・余裕がない |
| `seikatsu` | 毎日の生活 | 寝かしつけ・朝の支度・食事・生活リズム |
| `kodomo` | 子どもの様子 | イヤイヤ期・赤ちゃん返り・保育園・かんしゃく |
| `asobi` | 遊びと道具 | おもちゃ・知育・環境づくり（[[chiiku_policy_v1]]） |

**1記事1カテゴリ**。迷ったら「読む人がどんな状態か」で選ぶ（内容ではなく状態で分ける）。

## タグ（自由・検索語に寄せる）

記事で扱った**具体的な場面・年齢・モノ**を付ける。1記事3〜5個。

例: `怒鳴る` `後悔` `イライラ` `寝かしつけ` `朝の支度` `保育園` `イヤイヤ期`
`赤ちゃん返り` `動画` `偏食` `ワンオペ` `きょうだい` `知育おもちゃ` `2歳` `3歳`

**タグは検索語そのものを使う**（「感情調整」ではなく「イライラ」）。

## 並び順

- **新着** … 公開日の新しい順（`date`）
- **人気** … Cloudflare Web Analytics の実測ページビュー順（`scripts/web_analytics.py` が出力）
  - データが無いうちは表示しない（架空の人気順を作らない）

## ページ構成

| URL | 内容 |
|---|---|
| `/kosodachi/` | 一覧トップ（人気／新着／カテゴリ／タグ） |
| `/kosodachi/category/<slug>` | カテゴリ別 |
| `/kosodachi/tag/<タグ>` | タグ別 |
| `/kosodachi/<slug>` | 記事（末尾に同カテゴリの関連記事） |
