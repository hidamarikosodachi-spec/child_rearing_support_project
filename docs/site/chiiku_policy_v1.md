# 知育・道具・アフィリエイトの方針 v1（CEO見解）

> オーナー問い（2026-09-30）「知育関係はどこに置くか。自前サイトを持つなら知育道具のアフィリエイトや、
> 自社の知育製品も可能になるのでは」

## 結論（先に）

1. **知育は自前サイトに置く。** ただしカテゴリ名を「知育」にしない（後述）。
2. **アフィリエイトはやってよい。ただし収益は当面ゼロと見積もる**（計算は下記）。先に**運用ルール**を決めておく。
3. **自社製品は「物理」ではなく「デジタル」でやる。** 在庫・製造・返品は週3h とは両立しない。
4. **着手は読者が増えてから。** いま作っても読む人がいない。**記事の中で自然に触れる**ところから始める。

## 1. なぜ「知育」という看板を掲げないか

市場の「知育」は **「○歳までに」「地頭が良くなる」「差がつく」** の言葉で回っている。
これは本メディアが**明確に否定してきた立場**の真逆にある。

- ブランドの NG語: 絶対／必ず／○歳までに／天才／先取り／手遅れ
- 知識ベースで **× 指定**の流派（ヨコミネ式・七田式・公文式）は 1位推奨禁止
- 公開済の連載07 **「『教具を買わなきゃ』と思って疲れた日に」** ＝**買わなくていい**と書いた記事

**ここで煽り側に回ると、積んできた信頼が一度で消える。**

### 代わりに置くもの
カテゴリ名は **「遊びと道具」** とする。扱う問いは「何を買うべきか」ではなく、
**「これは買わなくていいのか／うちには要るのか」**。

これは逃げではなく**差別化**になる。
「買わなくていい」と言えるメディアは少なく、その一方で**親がいちばん知りたいのはそこ**だから。

## 2. 記事の型（「遊びと道具」カテゴリ）

```
# ＜モノの名前＞は必要か — 買う前に考えたいこと

## 結論
　買わなくていい場合／あったほうがいい場合を、最初に分けて書く

## なくても代わりになるもの   ← 先にこちらを書く（家にあるもので済む話）
## それでも欲しくなったら     ← 選ぶときの基準だけ。ランキングにしない
## うちの子には合わない、と感じたら
## 相談していいこと
```

**書かないもの**
- ランキング記事（「おすすめ10選」）
- 「買わないと遅れる」を匂わせる表現
- 実際に見ていないものの推奨
- 年齢で区切る断定（「2歳までに与えるべき」）

## 3. アフィリエイトの試算（正直な数字）

Amazon アソシエイトのおもちゃ類は**料率およそ2〜3%**。

| 月の売上（想定） | 報酬（3%） | 必要な購入数（単価3,000円） | 必要な月間PV（購入率1%） |
|---|---|---|---|
| 3万円 | 900円 | 10件 | 約1,000 |
| 30万円 | 9,000円 | 100件 | 約10,000 |

**いまの月間PV は実質ゼロ（訪問1件）。** つまり**アフィリエイトは今やっても1円にもならない**。
「自前サイトを持ったから収益化できる」という順序ではなく、**読者が先**。

→ **結論：仕組みは入れておく。期待はしない。** リンクは記事の自然な位置に1〜2本まで。

### 法令（必須）
2023年10月からの**ステマ規制（景品表示法）**で、広告リンクを含む記事には**明示が必要**。
- 記事冒頭に「**この記事にはアフィリエイトリンクを含みます**」と表示する
- プライバシーポリシーとは別に、この一文を記事テンプレートに固定で入れる
- 表示を怠ると法令違反。**例外なく入れる。**

## 4. 自社製品：物理ではなくデジタル

| | 物理（おもちゃ・教具） | デジタル（印刷して使える教材） |
|---|---|---|
| 初期費用 | 製造ロット・数十万円〜 | **ゼロ** |
| 在庫 | 抱える | **無し** |
| 発送・返品 | 発生する | **無し** |
| 不良・事故責任 | **重い**（乳幼児向けは特に） | 軽い |
| 週3h と両立 | ✗ | **○** |
| 可逆性 | 低い（在庫が残る） | **高い（下げれば終わり）** |

**物理はやらない。** 乳幼児向けの物理製品は安全基準・PL責任があり、個人事業＋週3h の体制で負う種類のリスクではない。

### デジタルなら、既にある資産で作れる
- **PDF生成パイプラインが既に動いている**（weasyprint・親向けガイドPDF の実績）
- **8タイプ診断がある** → タイプ別に出し分けできる

候補（読者が増えてから）:
- 「わが家の遊びの環境チェックシート」（タイプ別・印刷して冷蔵庫に貼る）
- 「声かけの言い換えカード」（連載05 NVC の内容をカード化）
- 「1日の流れを決める表」（小川タイプ向け＝生活リズムが崩れやすい人向け）

**有料化の順番は [[paid_ladder_v2]] のまま**（¥100 相性 → ¥300 タイプ別）。
デジタル教材はその次（2027年以降の検討）。

## 5. いつやるか

| 時期 | やること |
|---|---|
| **いま〜11月** | **やらない。** 記事の中で自然に触れる程度（連載07 の延長）。読者を増やすことに集中 |
| 月間PV 1,000 到達後 | 「遊びと道具」カテゴリを開始（3〜5本）。アフィリエイトの仕組みを入れる |
| 月間PV 5,000 到達後 | 本数を増やす。デジタル教材を検討 |

**判断の分岐点は「読者数」であって「サイトがあるかどうか」ではない。**
サイトはもう持っている。足りないのは読む人。

## 6. ひとつだけ、先にやっておくこと

**連載07「『教具を買わなきゃ』と思って疲れた日に」は、すでにこの立場で書いてある。**
自前サイト版（検索用）として「**知育おもちゃは必要か**」を1本書いておくと、
「遊びと道具」カテゴリの**旗**になる。買わせない記事が入口にあることで、あとで薦めるものが信用される。

→ 最初の10本（[[writing_voice_web_v1]]）に**11本目として追加**しておく。
