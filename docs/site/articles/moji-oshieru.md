# ひらがなを教えたほうがいいのか

同じ年の子が自分の名前を書いていると聞くと、焦りますよね。
ドリルを買うべきか、まだ早いのか、迷うところだと思います。

結論から言うと、**先取りして覚えさせる必要はありません**。ただし、**その前に育つもの**があります。

## 読み書きの前に育つもの

文字を読む力の土台になるのが、**音韻意識**と呼ばれるものです。

ことばを、音のかたまりとして扱える力のことです。

- 「りんご」が「り・ん・ご」の3つでできていると分かる
- しりとりができる
- 「か」から始まることばを探せる

**この土台があると、文字はあとから速く入ります。**
逆に、土台がないまま字形を覚えても、読むことにつながりにくいです。

## 家でできること

**1. しりとり**

いちばん手軽で、効果がはっきりしています。車の中でも、お風呂でもできます。

**2. 手をたたいて音を数える**

「た・ま・ご」で3回。名前や好きな食べ物でやってみてください。

**3. 絵本を指でなぞらずに読む**

**読み聞かせは、文字を教える時間ではありません**。
物語を楽しむ時間として残しておくほうが、本を好きでいてくれます。

**4. 名前の文字だけ、見える場所に置く**

自分の名前は、いちばん興味を持ちやすい文字です。
コップやタオルに書いてあれば、それで十分なことがあります。

## 教えないほうがいい教え方

- book や机に向かわせて、書き取りをさせる（嫌いになると、取り戻すのに時間がかかります）
- 読めた数を数える、ほかの子と比べる
- 間違いをその場で直す

**入学前に読めないことは、珍しくありません。** 小学校はそこから教える前提で作られています。

## 興味が出てきたら

子どものほうから「これなんて読むの？」と聞いてきたら、そこが始めどきです。

聞かれたときに答える。看板や商品名を一緒に読む。
**向こうから来るのを待つほうが、結果的に早いことが多いです。**

## こういうときは、相談していい

- しりとりが成立しない、音の区切りが分からない状態が5歳を過ぎても続くとき
- 聞き返しが多い、耳の聞こえが気になるとき
- 文字に限らず、ことばの発達全般が気がかりなとき

**保健センター**、**小児科**、**園の先生**に相談できます。

いま書けなくても大丈夫です。しりとりから始めれば、文字はあとから入ります。
