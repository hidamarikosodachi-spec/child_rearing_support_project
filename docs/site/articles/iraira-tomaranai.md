# イライラが止まらない日に

朝からずっと、何を言われても引っかかる日があります。
そういう日は、気持ちを立て直そうとするより、**先に体のほうを変える**ほうが早く収まります。

いまできることと、なぜそうなるのかを書きます。

## いま、この10分でできること

**1. 座ってください**

立ったまま子どもに話しかけている時間が長い日ほど、言い方はきつくなります。
しゃがむ、椅子に座る、それだけで声の大きさが変わります。

**2. 水を飲んで、何か口に入れる**

空腹と脱水は、そのままいらだちになります。
昼を抜いた日の夕方は、あなたの性格ではなく血糖値の問題です。

**3. 30秒、子どもと別の部屋にいる**

安全が確保できていれば、離れて大丈夫です。
「ちょっとお茶飲んでくるね」と言って出ても、見捨てたことにはなりません。

## なぜ、止まらなくなるのか

イライラは、感情ではなく**残量のサイン**として出てきます。

睡眠が足りない、休憩がない、ひとりの時間がない。
この3つがそろった日は、誰でも同じようになります。

子どもの行動が変わったわけではありません。
同じ「もう一回」に、昨日は笑えて今日は笑えない。
違っているのは、あなたに残っている量です。

だから、気持ちを入れ替えようとしても止まりません。
**先に体を休ませたほうが、結果的に早く収まります。**

## それでも、うまくいかない日のために

- **毎日おだやかに、は無理です。** 週に何度かはいらだつ。それがふつうです
- **子どもの前でイライラしても、壊れません。** 見せたあとに戻れば、それで十分伝わります
- **「今日は無理」と決めてしまって大丈夫です。** 夕飯を買ってきた日は、その日の勝ちです

## こういうときは、相談していい

- いらだちが自分でも止められないと感じるとき
- 手が出そうになった、または出てしまったとき
- 眠れない、食べられない日が続いているとき
- 何をしても気持ちが晴れない日が2週間以上続くとき

地域の**子育て支援センター**、**保健センター**、かかりつけの**小児科**に相談できます。
一時保育やファミリーサポートは、困り果ててから使うものではありません。
