# 発達が気になるとき、相談すると何が起きるか

ことばが少ない。癇癪が長い。呼んでも振り向かない。
夜、「発達障害 かも」と検索して、眠れなくなることがあると思います。

この記事では、**発達障害かどうかの判断はしません**。
代わりに、**相談するとどこで、何が起きるのか**を書きます。
流れが見えるだけで、相談への一歩は軽くなります。

## 相談は「診断を受けに行く」ことではありません

まず知っておいてほしいのは、
**相談の多くは、「様子を一緒に見ていく」ところから始まる**ということです。

いきなり病名をつけられる場ではありません。
「気になっている」と話すことが、最初の一歩です。

## どこに相談できるか

**1. 乳幼児健診（1歳6か月・3歳など）**

問診票の「気になること」の欄に書くだけで大丈夫です。
保健師や心理士が、話を聞いてくれます。

**2. 保健センターの発達相談**

健診を待たずに、電話で予約できることが多いです。
保健師・心理士が、子どもの様子を見ながら話を聞きます。

**3. かかりつけの小児科**

予防接種や風邪のついでに、「少し気になっていて」と伝えて大丈夫です。

**4. 保育園・幼稚園の先生**

家と園では、子どもの様子が違うことがあります。
園での様子を聞くと、見え方が変わることもあります。

## 相談したあと、何が起きるか

よくある流れは、次のようなものです（自治体によって違います）。

- **「しばらく様子を見ましょう」**：数か月後に、もう一度様子を確認する
- **親子教室を紹介される**：同じように気になる親子が集まり、遊びながら過ごす場
- **専門の機関を紹介される**：発達の専門医や、児童発達支援の窓口につながる

**診断がつかなくても、親子教室などの支援を使えることがあります。**
「診断を受けるかどうか」は、そのあとで考えても間に合います。

## 相談するときに、持っていくと役立つもの

- 気になる場面の**メモ**（いつ・どこで・どのくらい）
- 母子手帳
- できれば、気になる様子の**短い動画**

**相談の場では、うまく話せなくても大丈夫です。**
メモがあれば、それを見せるだけで十分伝わります。

## 「相談して何もなかった」も、立派な結果です

相談して「心配いらないですよ」と言われることも、たくさんあります。
それは、**行ったことが無駄だったのではなく、安心という結果を持ち帰れた**ということです。

迷っているなら、相談してください。
早めに相談して困ることは、ほとんどありません。

## こういうときは、早めに相談していい

- できていたことが、できなくなったとき
- ことばの遅れに加えて、目が合いにくい・呼んでも振り向かないなどが重なるとき
- 親のあなたが「何か違う」と感じ続けているとき

**保健センター**、**小児科**、**子育て支援センター**で相談できます。
