# ひとりで遊んでいるのが気になるとき

参観日に見に行ったら、自分の子だけ離れたところで遊んでいた。
先生に聞くと「ひとりで集中していることが多いですね」と言われた。

心配になるところだと思います。
ただ、**遊びには順番があって、ひとりで遊ぶ時期はその途中にあります**。

## 遊びが変わっていく順番

子どもの遊びは、だいたいこの順で広がります。

1. **ひとりで遊ぶ**（自分の世界の中で手を動かす）
2. **そばで、同じことをする**（隣で同じ積み木を積む。会話はない）
3. **同じ遊びを一緒にする**（役を分けて、やりとりが生まれる）

2の段階は**並行遊び**と呼ばれ、3〜4歳によく見られます。
外から見ると「一緒に遊んでいない」ように見えますが、**相手を見ながら真似しています**。

## 見ておくと安心できること

- 園以外の場所（公園・親戚の家）では、どう過ごしているか
- 名前を呼ばれたとき、こちらを見るか
- 遊びの内容が、くり返しだけで終わっていないか

**場所が変われば関わる子**なら、園での環境の問題であることが多いです。

## 家で、あなたができること

**1. ひとりで遊んでいる時間を、そのままにする**

集中している最中に声をかけると、途切れてしまいます。
**深く遊べる力は、あとで人と遊ぶときの土台になります。**

**2. 大人が遊び相手になる**

人とやりとりする練習は、同年齢の子でなくてもできます。
順番を待つ、交代する。家の中のほうが安全に試せます。

**3. 少人数で会う機会をつくる**

10人の輪より、1対1のほうが入りやすい子がいます。
園での様子だけで判断しなくて大丈夫です。

## 急がせなくていい理由

友だちと遊べる時期には幅があり、**5〜6歳でまとまって変わる子もいます**。

早くから集団に入れた子が、長い目で見て人づきあいが上手になるとは限りません。
**いま見えているのは、その子の順番の途中です。**

## こういうときは、相談していい

- 誘われても、まったく反応が返らないとき
- 遊びが同じ動きのくり返しだけで、長く続いているとき
- 園でも家でも、人への関心が薄いと感じるとき

**園の先生**、**保健センター**、**小児科**で相談できます。

ひとりで遊べることは、それ自体が力です。あとから人と遊べるようになっても、その力は残ります。
