# ひとりで抱えている日が続くとき

ひとりで回している日が続いているなら、いま必要なのは工夫ではありません。
**減らすこと**と、**外から人を入れること**です。

順番をまちがえると、どれだけ工夫しても足りません。

## 今週、先に削っていいもの

**1. 手作りをやめる**

買ってきたお惣菜で育つ子は、たくさんいます。
手をかけた食事より、夕方に笑える親のほうが、子どもには効きます。

**2. 掃除の頻度を落とす**

床が散らかっている家で、子どもは何も困りません。
片づけは、あなたに余裕が戻ってからで間に合います。

**3. 風呂を毎日にしない**

汗をかいていない日は、体を拭くだけで大丈夫です。
毎日入れなかった日があっても、何も起きません。

## 頼る先の順番

1. **一時保育**（自治体・保育園）— 理由は「リフレッシュ」で申し込めます
2. **ファミリーサポート**— 地域の会員制。送迎や数時間の預かりが中心です
3. **家事代行・宅配**— お金で時間を買えるなら、いちばん早く効きます
4. **子育て支援センター**— 予約なしで行けるところが多く、話を聞いてもらえます

「もっと大変な人がいる」と思って後回しにする必要はありません。
**支援は、限界の手前で使うものです。**

## なぜ、がんばりでは足りないのか

子育ての負荷は、**人手の数**でほぼ決まります。

研究でも、親の関わりの質を左右するのは性格や意欲ではなく、
**周囲からどれだけ支えられているか**だとくり返し示されています。

ひとりで2人を見るのと、2人で2人を見るのでは、必要な力がまったく違います。
うまくいかないのは、あなたのやり方の問題ではありません。

## それでも、うまくいかない日のために

- **今日を乗り切れたら、それで十分です。** 明日のことは明日考えて大丈夫です
- **子どもに謝る必要はありません。** 削ったのは家事であって、子どもではありません
- **助けを求めるのは、能力の問題ではありません。** 人手が足りないという事実の問題です

## こういうときは、相談していい

- 眠れない、食べられない日が続いているとき
- 子どもと2人でいるのがこわいと感じるとき
- 一日が終わるたびに涙が出るとき

**保健センター**の保健師さんに電話するところから始められます。
匿名で話せる相談窓口もあります。
