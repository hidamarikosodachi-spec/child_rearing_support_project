# 噛みつく・叩くと言われたとき

お迎えのときに先生から伝えられて、その場では「すみません」としか言えなかった。
帰り道、ずっとそのことを考えてしまう。

先にお伝えします。
**この時期の噛みつきは、性格の問題ではありません。** 言いたいことに、言葉が追いついていないときに起きます。

## なぜ、手や口が先に出るのか

2歳前後は、やりたいことと伝えられることの差がいちばん大きい時期です。

おもちゃを取られた。順番を抜かされた。
**頭の中には言い分があるのに、口から出るまでに時間がかかる。**
その数秒のあいだに、体のほうが動きます。

叱る回数を増やしても、この差は埋まりません。
減っていくのは、**言葉が増えたとき**です。

## 家で、あなたができること

**1. 起きた直後は、短く止める**

「噛むのは痛いよ」と、ひとこと。
長い説明は、この年齢では届きません。

**2. 言いたかったことを、代わりに言葉にする**

「取られたくなかったんだね」「まだ使いたかったね」。
**気持ちを言葉に置き換える練習**を、大人が何度も見せる形です。

**3. うまく言えた日に、それを言う**

「貸してって言えたね」。
できたときに触れるほうが、できなかったときに叱るより残ります。

## 園との付き合い方

先生から伝えられるのは、責めるためではなく、家庭と状況を合わせるためです。

「どんな場面で起きましたか」と聞いておくと、家でも同じ場面に気づけます。
**園とあなたが同じ言い方をすると、子どもは混乱しません。**

相手の保護者への謝罪は、園の方針に従って大丈夫です。
個別に連絡するかどうかは、園が判断します。

## 減っていく時期の目安

言葉が文になってくる**3歳前後から、はっきり減っていきます**。

いま毎日のように言われていても、半年後には話題にすら出なくなることがよくあります。
**いまが一生続くわけではありません。**

## こういうときは、相談していい

- 4歳を過ぎても、噛みつきや強い叩きが続くとき
- 相手に大きなけがをさせる強さがあるとき
- 言葉の発達にも気がかりがあるとき

**園の先生**、**保健センター**、**小児科**に相談できます。

いま伝えられている回数は、あなたの関わり方の評価ではありません。言葉が育つまでの時期のものです。
