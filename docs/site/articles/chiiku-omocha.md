# 知育おもちゃは必要か

結論から書きます。
**多くの場合、買わなくても足ります。** ただし、あったほうが助かる場面もあります。

その線引きを書きます。

## 買わなくていい場合

**家にあるもので、同じことが起きているとき。**

- 積む・並べる → 空き箱、タッパー、本
- 通す・入れる → ペットボトルとストロー、洗濯ばさみ
- 移す・すくう → スプーンと豆、コップと水
- ごっこ → タオル、空き容器、大人が使っている道具

子どもが集中しているとき、そこにあるのが玩具かどうかを、子どもは気にしていません。
**手を動かせて、繰り返せて、自分で終われるもの**なら、たいてい役目を果たします。

## あったほうが助かる場合

- **親が疲れていて、遊びを用意する余裕がないとき**（これは十分な理由です）
- **家にあるもので危ない**とき（小さすぎる、割れる、誤飲しそう）
- 子どもがその一点に強く集中していて、家のもので足りなくなったとき

## 選ぶときの基準

1. **子どもが自分で終われるか**（大人がつきっきりでないと成立しないものは続きません）
2. **繰り返せるか**（1回遊んで終わるものは、すぐ飽きます）
3. **答えが1つに決まっていないか**（決まっているほど、遊べる期間が短くなります）

「何歳から」の表示は目安です。**その子がいま何をくり返しているか**のほうが、あてになります。

## 買わなくていい、と言える理由

教育の考え方の多くは、**道具そのものより、環境の整え方**を大事にしています。

たとえばモンテッソーリでは、子どもが自分で手に取れる高さに、少ない数だけ置く——という形が中心です。
ここで効いているのは値段ではなく、**選べて、届いて、片づけられること**です。

たくさん買ったのに遊ばない、はよく起きます。
**数を減らすと遊ぶようになる**ことも、同じくらいよく起きます。

## それでも、迷う日のために

- **買った日があっても大丈夫です。** 後悔するほどの額でなければ、経験のうちです
- **まわりが買っていても、急がなくて大丈夫です。** 使う時期は子どもによって違います
- **「これで遅れる」ことはありません。** 早く始めたほうが有利だという確かな根拠は、多くの分野でまだ示されていません

## こういうときは、相談していい

- 遊び方が気になる、同じ動きだけをくり返すと感じるとき
- 集中が続かないことが心配なとき

**保健センター**や**保育園の先生**に聞けます。健診のときでも大丈夫です。
