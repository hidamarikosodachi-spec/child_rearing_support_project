# 自前サイトの文章 v1（提案）— 検索から来た人に書く

> `hidamari-kosodachi.com/kosodachi/<記事>` に載せる記事の方針。
> Threads/IG（物語）とも note（連載）とも**役割が違う**ので、書き方を分ける。

## 1. 誰に書くか

**夜23時、スマホで「子供 怒鳴ってしまう 後悔」と検索した人。**

- 子どもを寝かしつけたあと、後悔したまま検索している
- 読みたいのは物語でも理論でもなく、**「自分だけじゃないのか」と「明日どうするか」**
- 3秒で「ここに答えがありそうか」を判断して、無ければ戻る
- 落ち込んでいるので、責められたら閉じる

**note の読者（連載を追ってくれる人）とは別人**。関係がゼロの状態で、いきなり来る。

## 2. 3媒体の役割分担

| | 読者の状態 | 書き方 | 目的 |
|---|---|---|---|
| **Threads / IG** | 流し見している | **物語**（場面→ずれ→余韻） | 心を動かす・存在を知ってもらう |
| **note 連載** | 腰を据えて読む | **説明体**（こんな日→ある人はこう考えた→明日試せること） | 考え方を渡す・信頼を作る |
| **自前サイト** | 困って検索している | **実用体**（答え先出し→やること→なぜ→ただし） | 即座に助ける・見つけてもらう |

## 3. 記事の型（テンプレート）

```
# ＜検索語をそのまま含むタイトル＞
　例：「怒鳴ってしまった」と後悔する夜に — 今日できることと、明日からのこと

＜リード 2〜3行＞
　いま知りたいことへの答えを、最初に書く。前置きをしない。
　例：怒鳴ってしまった日は、やり直せます。取り返しがつかないことではありません。
　　　今夜できることと、次に同じ場面が来たときのことを書きます。

## 今夜できること（3つ・箇条書き）
　いますぐ実行できる具体だけ。理屈は書かない。

## なぜそうなるのか
　ここで初めて理論を1つだけ。名前は1回、説明は3行まで。

## それでも、うまくいかない日のために
　できない日を責めない。「毎日できなくていい」を明言する。

## こういうときは、相談していい
　医療・支援の窓口。必ず入れる（ブランドの約束）。

---
＜診断への導線（控えめに1回だけ）＞
```

## 4. トーンのルール

**note・SNS と共通で守るもの**
- 断定しない／親を責めない／NG語を使わない（絶対・必ず・○歳までに・天才・手遅れ）
- 医療の境界を必ず置く
- 改行は「1行だけ読んで意味が通る」位置で切る（[[feedback-line-breaks]]）

**自前サイトだけのルール**
1. **答えを最初に書く。** 検索の人は結論を待てない。物語で始めない。
2. **見出しだけで筋が通るようにする。** 本文を読み飛ばしても意味が取れる。
3. **箇条書きを使う**（note ではあまり使わない）。スマホで拾い読みできる形に。
4. **理論は1記事1つまで。** 名前は1回だけ。「モンテッソーリが」ではなく「ある保育の考え方では」で足りる場面も多い。
5. **1記事 1,200〜1,800字。** 連載より短く。読み切れる量。
6. **物語形式は使わない**（[[writing_voice_v1]] は Threads/IG 限定）。
7. **「あなた」を使ってよい**（note では避け気味だが、検索記事は1対1で話す）。

## 5. 最初に書く10本（検索語ベース）

実測で反応が大きかったテーマ（[[theme_performance_v1]]）＝自責が強い順に並べた。

| # | 想定検索語 | タイトル案 |
|---|---|---|
| 1 | 子供 怒鳴ってしまう 後悔 | 「怒鳴ってしまった」と後悔する夜に |
| 2 | 子供 動画 やめられない | 動画をやめられない子と、やめさせられない自分に |
| 3 | 赤ちゃん返り 上の子 対応 | 下の子が生まれてから、上の子が変わったと感じたら |
| 4 | 保育園 朝 泣く いつまで | 保育園の朝、泣かれて出てくるのがつらいとき |
| 5 | 子育て イライラ 止まらない | イライラが止まらない日の、いちばん小さな対処 |
| 6 | 寝かしつけ 時間かかる | 寝かしつけに1時間かかる日が続くとき |
| 7 | イヤイヤ期 疲れた | イヤイヤ期に疲れ果てた日に |
| 8 | 子供 言うこと聞かない 3歳 | 「何回言ってもやらない」が続くとき |
| 9 | 偏食 食べない 心配 | 食べない子のごはんが、毎日つらいとき |
| 10 | ワンオペ 限界 | ひとりで回している日が続いているとき |

> 順番は、**診断の自由記述（[[matcher]]）に集まった悩み**を見て組み替える。
> 実データが出るまでは、Threads の実測順で進める。

## 6. note との重複を避ける

同じ内容を両方に載せない（検索評価が割れる）。

| note | 自前サイト |
|---|---|
| 理論を軸にした読みもの（「アドラーの考え方をとなりに置く」） | 悩みを軸にした実用記事（「怒鳴ってしまった夜にすること」） |
| 連載として積む | 単体で完結する |

**関連する note 記事へは、自前サイトからリンクする**（逆はしない。検索評価を自前サイトに集めるため）。
