# 市場調査 v1 — 知育・子育て系の発信（2026-10-04）

> 一次データ: note の人気順フィード（#子育て/#知育/#幼児教育/#育児/#モンテッソーリ/#子どもの教育）から
> **170本**を取得し、各記事のスキ・本文長・価格・タグを API で実測した。
> ⚠️ これは「人気順に出てくる層」であって市場の平均ではない。**上澄みの姿**として読む。

## 1. 実測の数字

| 項目 | 値 |
|---|---|
| スキ 中央値 | **55.5**（平均 278・最大 10,025） |
| スキ分布 | 5〜19: 12本 ／ 20〜49: 62本 ／ **50以上: 96本** |
| 本文長 中央値 | **6,252字**（スキ上位20本でも 6,966字） |
| 有料記事の割合 | **4%**（7/170・価格は 100 / 100 / 250 / 400 / 1,200 / 1,500 / 2,980円） |

**自社との距離**: うちの連載は1本 1,800〜2,200字、スキは1記事あたり 0〜6。
人気層は**長さで3倍、スキで10〜50倍**。同じ土俵ではまだ戦えていない。

## 2. テーマの構成（人気順フィード内）

| テーマ | 本数 | 中央値スキ |
|---|---|---|
| 知育・学習（受験/英語/教材/AI活用） | 77 | 68 |
| エッセイ・その他 | 40 | 38 |
| 親のしんどさ・自己 | 34 | 53 |
| 夫婦・家族 | 33 | 53 |
| お金・働き方（副業/ワーママ） | 26 | 58 |
| 発達・療育 | 14 | 57 |
| 具体の困りごと（寝かしつけ/イヤイヤ/偏食 等） | 11 | 55 |

**読み取れること**

1. **「知育・学習」が最大派閥**（77/170）。ただし中身は**受験・英語・教材・AI 活用**が中心で、
   うちが扱う「0〜6歳の関わり方」とは別市場に近い。
2. **「具体の困りごと」は本数が最も少ないのに、スキ中央値は55と遜色ない**。
   つまり**供給が薄いのに需要はある**領域。うちの note と自前サイトはここに当たっている。
3. **お金・副業テーマの混入が多い**（26本）。育児タグを集客に使う副業アカウントが相当数いる。
   読者から見ると「育児の話を読みに来たのに営業だった」が日常的に起きている。
   → **売り込まない接触**（[[feedback-note-outreach-no-selling]]）は、この環境ではむしろ差別化になる。

## 3. 書き手の型

- **伸びている書き手は、同じテーマを何本も書いている**（同一著者の複数ランクイン: 幼児教室7本・元療育講師5本・サル母5本）。
  単発の良記事より、**同じ問題を連投する人**が面に出る。
- 最上位（スキ数千）は**子育てそのものではなく、人生観・社会論に振れた記事**。
  「僕は子育てをしない」「ご機嫌なおじさんを地球に納品する18年がかりのプロジェクト」など。
  **育児の実務記事がスキ1万に届くことはほぼない**。上限は現実的に数百。
- 肩書きが明確（元療育講師／幼児教室／双子ママ／パパ）な人がリピートされている。

## 4. タイトルの型（170本の出現率）

| 型 | 出現率 |
|---|---|
| 数字を入れる | 37% |
| 「」で発言を引用 | 27% |
| 【】で囲む | 19% |
| 体験談ワード（話/日記/記録/してみた/レポート） | 11% |
| 年齢を明示（◯歳） | 8% |
| 「？」で終わる | 4% |

**示唆**: うちは「」の引用型を多用していて、ここは市場と合っている。
一方 **数字と年齢がほとんど入っていない**。「2歳」「3つ」のような具体がない分、検索でも一覧でも拾われにくい。

## 5. 外の市場（大手メディア）

- **ベビーカレンダー**: 月間閲覧 約3.4億回・利用者 約1,206万人・**月約1,600本**を制作し、医師・助産師100名以上の監修網。
- **たまひよ**: Web 月間利用者 約381万人、アプリ約51万人。
- **トモニテ**: SNS フォロワー国内最大級。
- アフィリエイト視点では**育児ジャンルは大手が占有**しており、個人は売れ筋案件に特化して戦う領域とされる。

出典: [メディアレーダー 子育てメディア22選](https://media-radar.jp/contents/meditsubu/columns3-parentingmedia/) ／
[コノビー 子育て・ママ向けwebメディアまとめ](https://business.conobie.jp/marketing20210720) ／
[バリューコマース 育児ジャンルの攻め方](https://www.valuecommerce.ne.jp/stepup/affiliate_onayami4/)

**結論**: 「子育て 悩み」のような**大きな検索語で大手と正面から戦うのは不可能**（月1,600本・専門家100人の体制に対し、こちらは週3時間）。

## 6. 戦う場所（CEO の判断）

1. **知育は「教材・受験」側に行かない。** 最大派閥だが、大手と教材会社の土俵。
   うちは **「遊びと道具」＝買わなくてもできること**に寄せる（[[chiiku_policy_v1]] の方針を実測で追認）。
2. **「具体の困りごと × 親の自責」を取る。** 供給が薄く、需要はある。
   うちの自前サイト21本と Threads の実測（自責テーマほど伸びる・[[theme_performance_v1]]）とも一致する。
3. **同じ問題を何度も書く。** 単発ではなく、テーマを決めて連投する書き手が面に出ている。
   → 8タイプ連載のあと、**テーマ連投型**（例: 寝かしつけを角度を変えて5本）を試す。
4. **タイトルに数字と年齢を入れる。** 市場で37%が使っていて、うちはほぼ使っていない。次の記事から試す。
5. **長さは今のままでいく。** 人気層は6,000字だが、うちの強みは読みやすさ。
   ただし**自前サイトの検索記事は、薄いと検索で勝てない**ので、反応を見て2,500〜3,000字へ伸ばす余地を持つ。
6. **有料は4%しかいない＝課金は普通ではない。** 読者が少ない段階で高額を狙わない。
   ¥100→¥300 の階段（[[paid_ladder_v2]]）は、この実態と整合する。

## 7. 次に確かめること

- 自前サイトの記事に**数字・年齢を入れたタイトル**を混ぜ、クリック率を比べる（10月後半）
- 「具体の困りごと」カテゴリで、**同じ悩みを角度違いで連投**したときの伸び方（11月）
- 大手が手薄な**ロングテール検索語**を Search Console の実データから拾う（インデックス後）
