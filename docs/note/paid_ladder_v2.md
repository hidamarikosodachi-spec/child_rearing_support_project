# 有料記事の設計 v2：**¥100 相性 → ¥300 個別**（オーナー設計 2026-09-26・CEO受諾）

> v1（1万字まとめ ¥300 一本）から**全面変更**。[[paid02_matcher_book_plan]] は v1 の記録として残すが、**この v2 が正**。

## オーナーの設計（そのまま採用）

1. **母親が ¥100 の相性記事を買う**（「これくらいなら見てみよう」の価格）
2. 内容が当たっていると感じる → **夫にも診断をやってもらいたくなる**
3. さらに詳しい**自分の型の個別版（¥300）**を見たくなる

## CEO 評価：v1 より優れている。3つの理由

1. **入口の摩擦が桁違いに低い**。¥300 は「読む価値があるか」を考えてから買うが、¥100 は考える前に買える。
   いまの最大の壁は「買う人が1人もいない」ことなので、**最初の1件を出す確率**を最大化する設計が正しい。
2. **相性は、人を巻き込む**。診断そのものは1人で完結するが、相性は**相手にも診断させる動機**になる。
   → 診断の回答が増える（データが増える）／もう1人が読者になる／夫婦の会話になって共有されやすい。
   **日本で占い・相性ものが強いのは事実**で、ここは素直に利用していい（断定・格付けはしない、という条件つき）。
3. **¥300 を買う理由が生まれる**。いきなり ¥300 を売るのではなく、**¥100 で品質を確かめた人だけ**が上がってくる。
   売り込みが要らない。

### 私（Claude）の v1 案の誤り
- 「組み合わせを4通り無料で出して集客に使う」→ **その4組は買わなくなる**。無料で配る対象を間違えていた。
- 「1万字まとめ1本」→ 分量で価値を出す発想だったが、**読者が欲しいのは分量ではなく自分ごと**。

## 商品構成

### 商品A：¥100「わが家の組み合わせ」（**最初に出す**）
- 8タイプ × 8タイプ の**全36通り**（順序は問わない）を収録
- 1通りあたり 150〜250字：**ぶつかりやすい場面**／**どちらが何を担当すると楽か**／**子どもが両方から受け取っているもの**
- 全体で約9,000〜10,000字。¥100 としては厚く、**価格以上の体験**にする（ここで信頼を作るのが仕事）
- 冒頭の無料部分：相性を「診断」ではなく「担当の分け方」として扱う枠組みの説明まで。**組み合わせ表は1通りも無料で出さない**
- 末尾：「もっと詳しく知りたい方へ」→ 商品B（自分の型の個別版）へ

### 商品B：¥300「◯◯タイプの、もう少し細かい話」（**Aの反応を見てから**）
- タイプごとに独立した記事（最大8本）。中身は**そのタイプだけ**に絞る：
  - 時期による変化（0-1歳／2-3歳／4-6歳で、効く形が変わる）
  - しんどい日に、どこを捨てていいか（捨てる順番）
  - そのタイプの人が読むといい理論と、読まなくていい理論
  - よくある誤解（「自分は◯◯タイプだから△△できない」への反論）
- 各 4,000〜5,000字
- **8本いっぺんに作らない**。**A の購入者が多い型／診断の回答が多い型から2本**先に出し、反応を見る

## 価格と分量の逆転について（先に説明を用意しておく）
A（¥100）が約1万字、B（¥300）が約4,500字。**分量では逆転する**ので、記事内で役割を明記する。
- A＝**広さ**（36通りの早見表。家族・友人・保育者との関係にも使える）
- B＝**深さ**（自分の型だけを掘る。処方箋に近い）

## 絶対に守るガード（ブランド）
- **「相性が良い／悪い」と書かない。** 順位も点数もつけない。書くのは「ぶつかりやすい場面」と「担当の分け方」だけ。
- **占いにしない。** 「あなたは◯◯タイプだからこうなる」と決めつけない。いつも「傾向」「いまのところ」と書く。
- **どの組み合わせにも良さを書く。** 正反対の組み合わせほど、子どもが受け取るものが多い、という事実を必ず添える。
- 医療・発達の境界フックは全記事に置く。

## 見通し（正直に）
総PV 300弱・フォロワー1人の現状では、**A が数件売れれば上出来**です。
ただし ¥100 は「最初の1件」が出る確率がいちばん高い価格で、**1件出れば「買う人はいる」と確定**します。
その1件は、売上¥100 以上の価値があります（以後の全部の判断が変わるので）。

**A が 0 件だった場合**：テーマや価格ではなく**リーチ（読む人がいない）**の問題として扱い、値下げも取り下げもしない。
**A が売れた場合**：B を2本出し、A→B の移行率を見る。移行するなら 8本そろえる。
