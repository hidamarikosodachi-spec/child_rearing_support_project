# つくる前に、声を聞かせてください — アンケートのお願い

> 「ひだまりこそだち」は、これから子育ての発信を始めるところです。何をどう届けるかを決める前に、いま子どもと過ごしている方の声を聞かせてください。

## なぜ、先に聞くのか

子育ての情報は、もう十分すぎるほど世の中にあります。足りないのはたぶん、情報の量ではなくて、「うちの場合はどれを見ればいいんだろう」と思ったときに、隣に置いておける考え方なのではないか。そう考えて、この場所を準備しています。

ただ、つくる側が「これがいいはずだ」と思い込んで進めるのは、いちばん避けたいことでした。だから、形を決める前に聞きます。あなたが日々のなかで何に気をとられ、何があれば少し楽になりそうか。それが、これから何をつくるかの出発点になります。

## どんなことを聞きますか

子育てで気になっていること、どんな形（短い読み物／手元に置ける資料／自分に合いそうな考え方を見つけられる仕組み など）に魅力を感じるか、そして率直なところ、お金の感覚はどうか。うまく言葉にならない部分は、空欄のままで構いません。

「正解はひとつではない」という前提で読んでいただけたら、答えやすいと思います。

## おことわり

- **5分ほど**で終わります。ほとんどの項目は任意です。
- 答えたくない設問は飛ばして構いません。
- いただいた声は、これからの形づくりに使わせてもらいます。
- 営業のメールは送りません。連絡先の入力も任意です。

## 書いているのは

子育て中の、ふつうの親のひとりです。医師でも保育士でも研究者でもありません。
自分自身が「これでいいのかな」と迷いながら過ごしてきたなかで、同じように迷っている方と一緒に考える場がほしくなって、「ひだまりこそだち」をはじめました。
だから、正解を教えるのではなく、まず声を聞かせてもらえたら、と思っています。

## よかったら

（5分ほど・スマホで答えられます。ほとんどの項目は任意です。）

急ぎませんし、向いていないと感じたら途中でやめていただいて大丈夫です。あなたの「いま」を少し分けてくださること、それだけでとても助かります。

日々考えていることは note でも少しずつ書いています。連載「となりの考え方」も、よければあわせて覗いてみてください。

それでは、また。
