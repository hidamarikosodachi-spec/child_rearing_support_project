# 「何回言ったらわかるの」が口ぐせになった日 — 「ダメ」をことばにし直す

> 「ダメ！」「いいかげんにして！」が、気づけば一日の口ぐせになっている。
> 怒鳴ったあと、寝顔を見て落ち込む。
> 怒りたいわけじゃないのに、ほかの言い方が思いつかない。
> そんなときに使える、別の言い方の話です。

## こんな日、ありませんか

何度言っても片付けない。
ご飯は食べない。
出かける時間なのに着替えない。
「早く！」「ダメ！」「何回言ったらわかるの！」が、
気づけば口ぐせになっている。

言ったあとで、子の泣き顔や、ぴたっと黙った顔を見て、
こちらが落ち込む。
怒りたいわけじゃない。
ただ、ほかの言い方が思いつかなかっただけ。

先に言っておくと、あなたが冷たいわけでも、短気なわけでもありません。
ただ、別の言い方を習う機会がなかっただけです。
順番に書いていきます。

## ある人は、こう考えました

アメリカに、マーシャル・ローゼンバーグ（1934-2017）という心理学者がいました。
彼は、人の対立をほどく話し方として「非暴力コミュニケーション（NVC）」というものを考えました。
むずかしく聞こえますが、中身はとてもシンプルです。

彼は、人の怒りや反抗は「敵意」ではなく、「**まだ満たされていない、何かを必要とする気持ちの裏返し**」だと考えました。
子の「もうやだ！」も、自分の「いいかげんにして！」も、
その奥には満たされていない何かがある、と。

そのうえで、責めることばの代わりに、4つのことだけ口に出してみよう、
と言います。

1. **見たこと**（事実）── 「おもちゃが10個、床にある」
2. **自分の気持ち**── 「ママは焦ってる」
3. **必要としていること**（その気持ちの奥にあるもの）── 「寝る前に部屋を片付けたい」
4. **お願い**（断ってもいい頼みごと）── 「3つだけ一緒に片付けてくれる？」

ポイントは、「片付けなさい！」のような決めつけや命令を、
**事実と気持ちに置きかえる**ところです。
ローゼンバーグは前者を「ジャッカルのことば」、後者を「キリンのことば（＝事実と気持ちで伝えることば）」と呼びました。

そして彼は、何度もこう念を押しています。
「これは型ではなく、姿勢だ」と。
4つを完璧にそろえる必要はありません。

## 明日、試せること

### 「ダメ！」を、事実＋気持ち＋お願いに変える

寝る前、おもちゃが散らかったまま動かない子に。

つい出るのは「何回言ったらわかるの！もう全部捨てるからね！」。
これを、こう言いかえてみます。

「おもちゃが床にいっぱいあるね（見たこと）。ママ、寝る前に片付いてると落ち着くんだ（気持ちと、必要としていること）。3つだけ、一緒に片付けてくれる？（お願い）」

「全部片付けて」より「3つだけ」、「片付けなさい」より「一緒に」のほうが、
ずっと動いてくれます。

### イヤイヤ期、何を言っても「いや！」のとき

朝の着替えで全部「いや！」のとき。
「自分で決めたいんだね」と、まず気持ちを当ててみる。
そのうえで「赤い服と青い服、どっちにする？」と選んでもらう。
「いや」の多くは「自分で決めたい」のサインなので、
決める場所を渡すと、すっと収まることがあります。

### 「ママ嫌い！」と言われたとき

文字どおり受け取って傷つかなくて大丈夫です。
「いま、すごく嫌な気持ちなんだね。何かあった？」と、
ことばの奥を聞いてみる。
黙って待つのもありです。
自分の気持ちも、ついでに置いておく。
「ママは『嫌い』って聞くと悲しいな。仲良くしたいから」。
これだけで十分、伝わっています。

## ただし、ここは正直に

この話し方は、それを確かめた研究がまだ少なく、「こうすればこうなる」と言い切れるものではありません。
便利な一方で、使い方を間違えると別のしんどさを生みます。
そこは正直に書いておきます。

- **「型」を完璧にやろうとしない。** 「見たことは…、感じたのは…、必要としているのは…」と毎回きっちり言うと、
  不自然で、子に「ママ何言ってるの？」と返されます。
  本人いわく、これは型ではなく姿勢。
  疲れた日は「いま、ママ疲れた」のひとことだけでも十分です。
- **自分の気持ちを、我慢の道具にしない。** これは「親が感情を押し殺して優しく言う技」ではありません。
  むしろ逆で、自分の本当の気持ちに気づくための話し方です。
  怒っていてもいい。
  「いま、すごく怒ってる」と言うのも、立派にこの話し方です。
- **子に、大人の気持ちを背負わせない。** 「ママ、あなたのせいで悲しいの」を毎日伝えると、
  子が「ママを悲しませちゃいけない」と気を張るようになります。
  気持ちを伝えるのは、軽く、短く、「少し休んだら戻るね」くらいで。
- **危ないときは、のんびり言いかえている場合ではありません。** 道路に飛び出す、
  熱いものに触る ── そういう瞬間は、まず「ダメ！」で止めていい。
  言いかえは、そのあと落ち着いてからで間に合います。

それでも気がかりが強いときや、ご自身がつらいときは、
抱え込まずに地域の子育て支援センターや小児科に相談してください。
話し方の工夫は、相談の代わりにはなりません。

## おわりに

「何回言ったらわかるの」が口ぐせになっていた自分を、
責めなくて大丈夫です。
ほかの言い方を知らなかっただけで、子を思う気持ちは、
ずっとそこにありました。

そして、これも「正解」として渡すつもりはありません。
いつもこんなに丁寧に話せるわけがないし、その必要もありません。
1日に一回、「ダメ！」をひとつだけ言いかえられたら、
それでもう十分です。

このあとの回では、「子どもが主役の時間って、どういうことだろう」という話を、
汐見稔幸さんの「子ども主体の保育」からとなりに並べています。
