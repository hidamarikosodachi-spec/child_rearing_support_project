# 動画をやめられない夕方に — 5万8千人の日本の子どもを追った調査と、終わらせ方

夕方の5時40分。
台所でみそ汁の鍋を火にかけた母親が、ふと壁の時計を見る。

リビングのソファでは、2歳の息子がタブレットを両手で持っている。
画面の光で、ほおがほんのり明るい。
口が少し開いたまま、動かない。

「ごはんだよ。おしまいにしよう」
返事はない。

「あと1回ね」と言って、母親はもう一度、台所に戻る。
5分後も同じ画面で、同じ姿勢のままだった。

こういう夕方を、思い当たる人は多いと思います。
この記事では、日本の子どもを追った大きな調査で分かっていることと、
分かっていないこと、そして今日からできる終わらせ方をまとめます。

## 日本の5万8千人を、1歳から3歳まで追った調査

2023年に、千葉大学の山本さんらが
**「テレビ・DVDを見る時間」と「子どもの発達」の関係**を
調べました。
全国15の地域で生まれた**57,980組**の親子を、
1歳・2歳・3歳の3回の時点で追っています。

- 見る時間は、**親が答えた「テレビ・DVDの視聴時間」**
- 発達は、**親が記入する発達の質問票（ASQ-3）**で測っています

結果は、2つありました。

**1つめ。** 1歳のときにテレビ・DVDが長めだった子は、
2歳のときの発達の得点が、わずかに低めでした（β＝−0.05）。
2歳から3歳でも、同じ向きの関連がありました（β＝−0.08）。

数字としては小さな関連です。
「見せたから遅れる」と言い切れるものではありません。
ただ、著者たちは、1歳からの視聴の増え方が
あとの発達の得点と関わっていた、とまとめています。

**2つめ。** 逆の向きも見つかりました。

言葉のやりとりの得点が低めだった子ほど、
**翌年のテレビ・DVDの時間が長くなる**傾向がありました
（1歳→2歳でγ＝−0.03、2歳→3歳でγ＝−0.06）。

つまり、見る時間が長くなる流れは、
「見せすぎた親」だけで起きているのではなさそうです。
言葉でのやりとりが少し難しい時期の子には、
画面のほうが楽に付き合える、ということも起きています。
親が頼りたくなる事情には、理由があります。

## ここから読み取れること、読み取れないこと

- 見せた日があること自体は、責める材料になりません
- **「何時間までなら安全」という線は、この調査からは引けません**
- 関連があることと、原因であることは別です

この調査には、限界もあります。

- 測っているのは**テレビ・DVD**です。
  いまの家庭に多い
  スマホやタブレットでの動画は、そのまま当てはまるとは限りません
- 発達の質問票は**親の記入による目安**で、診断ではありません
- 観察した研究なので、家庭の事情など、ほかの要因を
  すべては取り除けていません
- 自閉スペクトラム症などの子は、分析から除かれています

## 今日からできる、終わらせ方

画面の時間そのものより、
**終わるときに、ぶつからずに済む形**を先に決めておくほうが、
夕方は回りやすくなります。

**1. 渡す前に、終わりを言う**

「2本ね」と言ってから渡します。
「あと5分」より、**本数**のほうが、子どもには終わりが
見えやすいようです。

**2. 止める役を、タイマーに任せる**

鳴ったら終わり。
止めるのが大人ではなくなるので、
「ママがやめさせた」という対立が起きにくくなります。

**3. 終わったあとの予定を、先に言う**

「これが終わったら、ごはん。食卓まで、手をつなごうね」。
次がないと、終わりは「取り上げられた」だけになります。

**4. ときどき、隣で一緒に見る**

アメリカ小児科学会も、小さな子には、親が一緒に見て
話しかけながら使うことを勧めています。
「なに見てるの？」と隣に座る。
それだけで、画面の前の時間が、親子の会話の時間に変わります。

不満そうに泣く日もあります。
予告どおりに終えたなら、約束を守った日です。
長く見せた日があっても、翌日に戻せば足ります。

## こういうときは、相談していい

- 動画をやめたあと、長く立て直せない日が続くとき
- 睡眠や食事が、はっきり削られているとき
- 言葉のやりとりが減っている、呼びかけへの反応が少ないと感じるとき

**小児科**、**保健センター**、**子育て支援センター**で
相談できます。
健診のときに聞いておくのも、よい方法です。
**親が休めなくなっていることも、相談していい理由です。**

## おわりに

あの夕方、母親は鍋の火を止めて、息子の隣に座る。
「なに見てるの？」と聞くと、息子は画面を指さした。
「あと1本ね」と言うと、息子は小さくうなずいた。

その1本が終わったあと、タブレットは暗くなって、
ソファに置かれたままになる。
湯気の立つごはんのほうへ、2人で手をつないで歩いていく。
