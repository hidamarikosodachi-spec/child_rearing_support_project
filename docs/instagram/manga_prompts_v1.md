# 漫画リールの絵のプロンプト v1（ChatGPT で無料生成・オーナー作業）

> 費用はかけない（2026-11-04 オーナー判断）。絵はオーナーが ChatGPT で作り、文字入れと動画化は Claude が行う。
> 題材は 11/5 公開の note「やさしい子に育ってほしい」と願うなら（Warneken 2008）。

## 使い方

1. ChatGPT で**新しいチャットを1つ**開き、①→②→③→④→⑤の順に、**同じチャットの中で**送る（同じ顔で描かせるため）。
2. できた絵を保存して、Claude に渡す（チャットに貼る）。
3. ナレーションの箱・吹き出し・最後の研究のコマは、Claude がプログラムで足す。**絵には文字を入れない。**

## ① キャラクター見本

```
これから縦長の漫画を数コマ描いてもらいます。まず登場人物の見本を1枚作ってください。

・30代の母親：肩までの茶色い髪をひとつに結んでいる。ベージュのゆったりした部屋着。やさしい顔立ち。
・1歳半の子ども：短めの黒髪、ぷっくりした頬、黄色いトレーナーと紺色のズボン。
・2人が並んで立っている全身の見本。正面と横向き。

絵柄：やわらかいアニメ調の手描きイラスト。写真のようなリアルな絵にはしない。
色：クリーム色・オレンジ・薄い黄色を中心にした、あたたかい色合い。
文字・吹き出し・ロゴは一切入れない。
```

## ② 1コマ目

```
同じ2人で、縦長（9:16）の漫画の1コマを描いてください。

場面：昼間のリビング。母親が床に座って洗濯物をたたんでいる。
その横で、1歳半の子どもが、たたむ前のタオルを1枚、両手で引きずるように持ってきている。
母親はまだ子どもに気づいていない。

画面の上から4分の1は、あとで文字を入れるので、壁や窓だけの何もない空間にしてください。
絵柄・色・人物は見本と同じ。文字・吹き出しは一切入れない。
```

## ③ 2コマ目

```
続きの1コマを、同じ2人・同じ部屋・縦長（9:16）で描いてください。

場面：子どもがタオルを両手でぐいっと母親に差し出し、母親の顔を見上げている。
子どもは少し得意そうな顔。母親は少しおどろいて、手を止めている。
子どもの顔のアップ寄りの構図。

画面の上から4分の1は何もない空間にしてください。文字・吹き出しは一切入れない。
```

## ④ 3コマ目

```
続きの1コマを、同じ2人・同じ部屋・縦長（9:16）で描いてください。

場面：母親がしゃがんで子どもと目の高さを合わせ、両手でタオルを受け取っている。
母親はにっこり笑っている（何かを手渡したり、お菓子やシールをあげたりはしていない）。

画面の上から4分の1と、母親の顔の横は、あとで文字を入れるので何もない空間にしてください。
文字・吹き出しは一切入れない。
```

## ⑤ 4コマ目

```
続きの1コマを、同じ2人・同じ部屋・縦長（9:16）で描いてください。

場面：子どもが、洗濯物の山からもう1枚タオルを取りに、うれしそうに小走りで向かっている後ろ姿。
母親はそれを見守って、やわらかく笑っている。

画面の上から4分の1は何もない空間にしてください。文字・吹き出しは一切入れない。
```
