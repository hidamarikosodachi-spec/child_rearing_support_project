# note 連動リールの型 v1（オーナー指示 2026-10-18）

> 「Instagram は note 記事への最大限の導線に」「親が取るべき行動や、○○から学ぶ子育ての考え方など、親の行動を促す内容にして、詳しくは note で」

## 決まりごと

- **その日の note 記事から作る**（同じ日に出す）。リールで興味を持った人が、プロフィールのリンク → /note/ のいちばん上でその記事に届く。
- **中身は2種類だけ**:
  - **行動型**: 「親が今日からできる3つ」。1枚に1つの行動。
  - **学び型**: 「○○（理論・研究者）から学ぶ」。考え方を1つ、行動を1つ。
- **理由・研究の詳細・限界・相談の目安は note に回す**（リールには書ききらない）。
- **最後の1枚**: 「◯◯は note に書きました｜プロフィールのリンクから」。
- **キャプションの最後**: 「詳しい理由（研究の限界も）は note に書きました。プロフィールのリンクから読めます」。
- 命令口調にしない（「〜すべき」→「今日、ひとつだけ」）。医療の断定をしない。
- 文字は静止（ズーム禁止・[[feedback-reel-no-zoom]]）。1行20字前後・文節で改行。

## 枚数の目安（15〜25秒）

1. 表紙（誰の・どんな場面の・何がわかるか）
2. 場面（1〜2行）
3〜5. 行動 or 考え方（1枚1つ）
6. 研究・理論の一言（あれば）
7. note への誘導

## 測り方

- IG 側: 再生・保存・シェア（`experiment_track.py`）
- note 側: /go/<key>?s=ig のクリック数（D1 clicks）＋記事PV（`note_experiment.py`）
