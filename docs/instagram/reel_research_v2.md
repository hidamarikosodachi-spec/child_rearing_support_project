# Instagram リール調査 v2 — 育児系ショートで再生される形式（2026-11-04）

> v1（10/6）は一般論の二次情報だけだった。v2 は **YouTube ショートの公開データ**（再生数・登録者）を代わりに使った実測。
> Instagram 本体には触れていない（自動操作はしない方針のまま）。主要な数字は3本を curl で再取得して一致を確認済み。

## 0. 自社の現状（API・11/4）

- リール11本の**平均視聴時間は 0.8〜3.3秒**（1本は約14秒）。最初の1枚で離脱されている。
- 冒頭は全本同じ型＝クリーム背景＋タイトル文字のみ。人・絵・動きなし。
- 10/6 の判定「再生50を超えなければ月1に落とす」は**判定を落とし**、毎日出し続けていた。

## 1. 調べたこと

育児系の YouTube ショート21チャンネル、各チャンネルの直近48本の再生数を取得し、形式をサムネイルから判定した。

| 形式 | 例（登録者） | 再生の中央値（最大） |
|---|---|---|
| 実写：子どもとの場面・手元の実演 | 保育士バンク(17.8万)／ふじこ(6.7万)／よっぴ(447) | 1万（70万）／1.55万（671万）／7千（15万） |
| 顔出しの解説 | てぃ先生(85.6万)／コアラ先生(2.75万) | 26万／7千 |
| イラスト＋大きな文字＋「◯選」・50〜60秒 | 心と知恵の子育て雑学(2.3万)／ポジティブママ(1.3万) | 2.3万（193万）／4千（41万） |
| **テキストのみのスライド・約10秒（＝いまの自社）** | 4チャンネル（登録者7〜41） | **61〜745（最大4千）** |
| 漫画・アニメ | ママスタ(2.3万)／けんぴ(514) | 7千／1.5千 |

## 2. 同じチャンネル内の比較（いちばん確かな証拠）

- **保育士バンク**：声かけ場面の実写 58万・子ども目線 70万 ／ 大人が座って話すインタビュー 中央値4千
- **よっぴ**：寝かしつけ・おむつの手元実演 4〜15万 ／ いらすとや＋説明スライド 1.5〜2.4千
- **ふじこ**：赤ちゃんが泣き止む場面 671万 ／ カメラに向かって話すだけ 1千前後

## 3. 結論

1. **実写の「子どもとの場面」「手元の実演」がいちばん伸びる**（チャンネル内比較3件が同じ向き・確度 中〜高）。
2. **人が出ない形式なら、イラスト＋大きな文字＋「◯選」の箇条書き＋50〜60秒**が登録者の数倍〜80倍再生されている（4チャンネル・確度 中・音声は未確認）。
3. **テキストのみのスライドは上限が数千回**。大きいチャンネルで続けている例が無い（確度 中）。
4. 同じ形式の中では、**題名の型で数十倍の差**がつく。伸びるのは「親が自分の子に当てはめて確かめたくなる」題名（確度 中）。
5. 漫画・アニメは、知識を伝える用途では今回強くなかった（確度 低）。

## 4. 確認できなかったこと

- 音声（ナレーションの有無・AI音声か）／冒頭1秒の実際の画面／視聴維持率
- 各チャンネルの歴代上位（直近48本のみ）／公開日を揃えた比較
- Instagram 上での数値（YouTube ショートでの代替調査）
