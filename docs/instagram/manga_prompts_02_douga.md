# 漫画リールの絵のプロンプト 02 — 動画をやめられない（探索期 第2段階1本目・G2 困りごと×T2 物語体）

> 題材の理由: Threads「動画をやめられない」239 views（困りごとの上位）・note では未出。
> 使い方は [[manga_prompts_v1]] と同じ。**前回と同じ ChatGPT のチャット**で①から送る（同じ親子の顔にするため）。

## ① 1コマ目

```
前回と同じ母親と子どもで、新しい場面の漫画を縦長（9:16）で4コマ描いてください。まず1コマ目です。

場面：夕方のリビング。子どもがソファに座って、タブレットの動画に夢中になっている。顔は画面の光でほんのり明るい。
奥の台所で、母親が夕ごはんの支度をしながら、壁の時計をちらっと見ている。
タブレットの画面は光っているだけにして、アプリやキャラクターは描かない。

画面の上から4分の1は、あとで文字を入れるので、壁だけの何もない空間にしてください。
絵柄・色・人物は前回と同じ。文字・吹き出しは一切入れない。
```

## ② 2コマ目

```
続きの1コマを、同じ2人・同じ部屋・縦長（9:16）で描いてください。

場面：母親が子どもの横にしゃがんで、タブレットを取り上げずに、一緒に画面をのぞきこんでいる。
子どもは画面を見たまま、少し母親のほうに体を寄せている。母親はおだやかな顔。

画面の上から4分の1は何もない空間にしてください。文字・吹き出しは一切入れない。
```

## ③ 3コマ目

```
続きの1コマを、同じ2人・同じ部屋・縦長（9:16）で描いてください。

場面：母親が人差し指を1本立てて子どもに見せている。子どもは母親の指を見て、こくんとうなずいている。
2人の顔が見える、少し寄った構図。

画面の上から4分の1と、母親の顔の横は、あとで文字を入れるので何もない空間にしてください。
文字・吹き出しは一切入れない。
```

## ④ 4コマ目

```
続きの1コマを、同じ2人・同じ部屋・縦長（9:16）で描いてください。

場面：画面が暗くなったタブレットがソファに置いてある。
子どもは少し口をとがらせて不満そうだけれど、母親と手をつないで食卓のほうへ歩いている。
食卓には湯気の立つ夕ごはん。2人とも後ろ姿か横顔。

画面の上から4分の1は何もない空間にしてください。文字・吹き出しは一切入れない。
```
