# Instagram リール調査 v1 — 育児・知育系で再生される型（2026-10-06）

## 0. 調べられなかったこと（先に明示）

**他社リールの再生数は取得できなかった。** 理由は2つ。

1. **ハッシュタグ検索 API が使えない**。`ig_hashtag_search` は Facebook ログイン方式専用で、
   こちらは Instagram ログイン方式（FBページ無し）。実際に叩いて `code:100 Unsupported get request` を確認した。
2. **ブラウザでの収集はしない**。Threads と同一アカウント系列のため、凍結の連鎖リスクを負わない（既定方針）。

したがって本調査は **①自社の実測 ②公開されている運用知見（二次情報）** の2本立てで、
「他社の再生数ランキング」ではない。二次情報は出典を併記する。

## 1. 自社の実測（ここがいちばん確か）

| 投稿 | 形式 | 再生 | リーチ | いいね | 保存 | シェア |
|---|---|---|---|---|---|---|
| 2026-06-10 絵本リール | 手描きアニメ（roughjs・色鉛筆タッチ） | **111** | 105 | 0 | 0 | 0 |
| 2026-10-01 「あと1本だけ」 | **静止スライド8枚・1枚約4秒・29秒** | **18** | 16 | 0 | 0 | 0 |

**スライド方式は、手描きアニメの1/6しか再生されていない。**
投稿時点のフォロワー数はほぼ同じ（1人）なので、差は中身の側にあると見るのが妥当。

仮説: **動きがなく、1枚4秒も止まるため、冒頭で離脱している。**
いまのアルゴリズムは後述のとおり視聴維持率を強く見るので、静止画の長い保持は最も相性が悪い。

## 2. 2026年のアルゴリズムで効くもの（二次情報）

- 評価軸が **「保存・いいね」から「視聴維持率」と「シェア」へ移った**
  （[逆転ラボ](https://gyaku-ten.jp/column/instagram-20260710)／[ココマーケ](https://www.cocomarke.com/blog/instagram-reels-growth-guide-2026/)）
- アルゴリズムが見る3指標は **3秒視聴維持率・保存率・シェア率**。目安は
  **視聴維持率40%以上／保存率1〜3%以上**、再生完了率は50%以上が目標
  （[アドネス](https://addness.co.jp/media/instagram-reel-playcount/)／[マーケティングワン](https://marketingone.co.jp/instagram-reels-cvr-creative-guide-2026/)）
- **冒頭3秒で離脱される**のが最大の失敗。視聴者は**0.5秒**で「自分向けか」を判断する
  （[オアソビ](https://note.com/oasobi12/n/n06dae3d205a9)）
- **教育型リールの推奨構成** = 悩み提示 → コツ3点 → 注意点 → 保存/プロフ誘導。
  **20〜45秒／8〜14カット**。保存率が高く「資産型」とされる（同上・[tatap](https://tatap.jp/knowledge/instagram-reel-185/)）

### 冒頭1秒のフック型（そのまま流用できる）

1. 結論先出し「◯◯の原因、これです」
2. 問題のつつき「まだこのやり方してませんか？」
3. ビフォーアフター「同じ子でも、ここまで変わります」
4. 数字「この言い方で、朝の支度が10分縮みました」
5. 否定「実は、何度言っても伝わりません」
6. 自分語りの入口「怒鳴ってしまった夜の話です」
7. 引き「このあと、正直後悔しました…」
8. 比較「伝わる言い方と、伝わらない言い方」
9. 直球の問い「その言い方、届いていますか？」

**うちで使えるのは 3・4・5・6・8。** 1・2・7・9 は煽りに寄るので使わない
（「親を責めない」の線を越える）。

## 3. 人気アカウントの形（二次情報）

- 育児系で規模が大きいのは**生活・ファッション・コストコ等の「暮らし」寄り**で、
  理論を扱う発信は上位に見当たらない（[find model](https://find-model.jp/insta-lab/instagram-mother-influencer/)）
- 知育・育脳・英語育児・絵本紹介の専門アカウントで**フォロワー10万規模**の例がある
  （[influencer-company](https://influencer-company.info/influencer-column/mama-instagramer/)）
- note の市場調査と同じ構図: **知育＝教材・英語・受験**が主流で、
  「関わり方の理論」は空いている

## 4. いまのリールの何を変えるか（決定）

| 変える点 | いま | これから |
|---|---|---|
| 1枚の尺 | 1.8〜4.0秒 | **1.4〜2.6秒**。全体20〜30秒に足りない分は**スライドを増やして**稼ぐ（原稿を12〜14枚にする） |
| 動き | 完全に静止 | **ゆっくりズーム／パン**を全カットに入れる |
| 冒頭 | 表紙3.75秒（タイトルのみ） | **1秒以内に悩みのテロップ**＋動き。表紙で止めない |
| 構成 | 場面→ずれ→余韻 | **悩み提示 → 言い換え3つ → 注意点 → 保存の一言** |
| 終わり | タグライン | **最初の画へ戻るループ**＋「保存して、夕方に見返してください」 |

文体の決まり（主語を省かない・オチをつけない・感情語を名指ししない）は維持する。
**煽り系のフックは使わない。** 視聴維持のために親を不安にさせる書き方はしない。

## 5. 判定

- 次の2本（10/8・10/15）を上記の形で出し、**再生数が 18 → 50 を超えるか**を見る。
- 超えなければ、**リールは月1に落として note と自前サイトに資源を戻す**
  （IG は反応率は高いが、現状フォロワー1人で到達の土台がない）。
- インサイトは `scripts/instagram_comments.py` と同じ経路で取得できる（views/reach/saved/shares）。
