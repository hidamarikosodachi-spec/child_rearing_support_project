## なぜ変えるか

- Instagram で押せるリンクは、プロフィールの1本だけ。そこを **note の入口**にする。
- /note/ のいちばん上は「今日の記事」＝その日のリールと同じ記事。見た話の続きにすぐ届く。
- リンクは /go/ 経由で記録される＝ **Instagram から何人が note に移ったか**が分かる（D1 clicks）。
