# リール（10/7）寝かしつけに1時間かかる夜

構成＝悩み提示 → 試せること3つ → 注意点 → 保存の一言（13カット・約25秒）。

## スライド本文

**1枚目（表紙）**
寝かしつけに
1時間かかる夜
— 私が先に限界だった

**2枚目**
布団に入って、もう40分。
私の腕は、下敷きのまま
しびれている。

**3枚目**
となりで娘は、
天井を見ながら
足をばたばたさせている。

**4枚目**
「まだ寝ないの」と言うと
目がぱっちり開く。
私の声が、起こしている。

**5枚目**
眠りに入るには、
体温が下がる必要があります。
お風呂から1時間ほどかかります。

**6枚目**
「寝なさい」
↓
「目をつぶって、
おふとんの中を暗くしよう」
（眠れとは言わずに、形だけ渡す）

**7枚目**
「もう遅いよ」
↓
「あと1回だけ、
背中トントンしようか」
（終わりの形を先に決める）

**8枚目**
「静かにして」
↓
（声をかけず、
こちらが先に目を閉じる）
（親の呼吸が、合図になります）

**9枚目**
部屋は暗いほうが進みます。
豆電球より、真っ暗のほうが
眠りに入りやすい子が多い。

**10枚目**
それでも寝ない日は
あります。

**11枚目**
その日は、
寝かしつけに失敗したのではなく
今日はそういう日だった。

**12枚目**
私が先に寝てしまっても
大丈夫です。
となりにいること自体が、
いちばん効いています。

**13枚目**
眠るのは子どもの仕事で、
私の仕事は
そばにいることまで。
→ 保存して、今夜のおふとんで

## キャプション

布団に入って40分。私の腕は下敷きのまましびれていて、となりで娘は天井を見ながら足をばたばたさせている。

「まだ寝ないの」と言うと、目がぱっちり開く。私の声が起こしている、と気づいた夜がありました。

眠りに入るには体温が下がる必要があって、お風呂から1時間ほどかかります。だから「寝なさい」ではなく、形だけ渡すようにしています。

「目をつぶって、おふとんの中を暗くしよう」
「あと1回だけ、背中トントンしようか」
それから、こちらが先に目を閉じる。

それでも寝ない日はあります。その日は失敗したのではなくて、今日はそういう日だった、ということで。

保存して、今夜のおふとんで思い出してもらえたらうれしいです。
