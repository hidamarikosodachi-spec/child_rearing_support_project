# 漫画リールの絵のプロンプト 03 — 「早くしなさい」を言ってしまう朝（IG-2・3コマ・14秒前後）

> 実験 IG-2：**22秒 → 14秒前後**に詰めて、平均視聴の維持率（いま約3割）が上がるか。コマ数は **3**（前回は4）。
> 題材の理由：Threads で「叱り方」408・「言い方がきつくなる」139 など、**親が後ろめたい場面**が強い。同じ日の Threads 11/10 と同じ場面。
> 使い方は [[manga_prompts_02_douga]] と同じ。**前回と同じ ChatGPT のチャット**で①から送る（同じ親子の顔にするため）。
> 画像は 1080×1920 で、`video_manga_03_panel_1.png`〜`3.png` の名前でリポジトリ直下に置いてください（前回と同じ置き方）。

## ① 1コマ目

```
前回と同じ母親と子ども（女の子に変えず、前回と同じ男の子）で、新しい場面の漫画を縦長（9:16）で3コマ描いてください。まず1コマ目です。

場面：朝の玄関。子どもが床に座って、片方だけ靴下をはいたまま、ぼんやり窓のほうを見ている。
母親は立ったまま、腕時計（または壁の時計）を見て、眉を寄せている。ランドセルではなく、保育園の黄色いカバンが床に置いてある。

画面の上から4分の1は、あとで文字を入れるので、壁だけの何もない空間にしてください。
絵柄・色・人物は前回と同じ。文字・吹き出しは一切入れない。
```

## ② 2コマ目

```
続きの1コマを、同じ2人・同じ玄関・縦長（9:16）で描いてください。

場面：母親が子どもの前にしゃがんで、靴下をはかせている。母親の口はへの字で、早口で何か言っている様子。
子どもは母親の顔を、じっと見上げている。表情は少しこわばっている。
2人の顔が見える、少し寄った構図。

画面の上から4分の1は何もない空間にしてください。文字・吹き出しは一切入れない。
```

## ③ 3コマ目

```
続きの1コマを、同じ2人・同じ玄関・縦長（9:16）で描いてください。

場面：母親が子どもを後ろからそっと抱きしめている。母親は目を閉じて、少し肩の力が抜けている。
子どもは黄色いカバンを胸に抱えて、母親の腕に手を添えている。
玄関のドアの小窓から、朝の光が差している。

画面の上から4分の1は何もない空間にしてください。文字・吹き出しは一切入れない。
```
