# ポジショニング v2 — 学術で戦う相談パートナー（オーナー決定 2026-10-04）

## 決定

> **実体験ではなく学術で戦う。相談パートナーとして、「どんな子に育てたいか」「自分はどう関わればいいか」を一緒に考える、安心できる場になる。**

[[market_research_v1]] の実測を踏まえたオーナーの決定。v1 からの変更点は次のとおり。

| | v1（これまで） | **v2（これから）** |
|---|---|---|
| 立ち位置 | 悩みに寄り添うエッセイ媒体 | **相談パートナー**（考えを一緒に整理する相手） |
| 根拠 | 共感と実感 | **学術・理論**（出典を見せる） |
| 読者の問い | 「この困りごとをどうする？」 | 「**どんな子に育てたいか**」「**自分はどう関わるか**」 |
| 勝ち筋 | 体験談の量 | **知識ベース×診断のパーソナライズ** |

## なぜこれで戦えるか

1. **体験談市場では勝てない**（一次体験が薄い）。市場調査の上位は体験談・人生論で、そこは別の人の土俵。
2. **学術の裏付けを持つ個人発信者がほとんどいない**。461ファイルの知識ベース（理論の tier 分類・論文サマリ・育児書要約）は模倣に時間がかかる。
3. **大手メディアは「網羅」はできても「あなたに合わせる」ができない**。診断（8タイプ・D1に蓄積）と理論を組み合わせると、
   「あなたは野原タイプなので、こうつまずきやすく、ピクラーの考え方が助けになります」が言える。これは体験談でも教材紹介でもない場所。

## これに伴って変えること

### 1. 出典を読者に見せる（最優先・方針転換）

いままで note への入稿時に、**出典ブロックを切り落としていた**（`BODY_END = "\n---\n\n> **出典"`）。
学術で戦うと決めた以上、**出典は読者が見える位置に置く**。参考文献は信頼の裏付けであり、隠すものではない。

- note: 本文末に「**この記事のもとになった考え方**」として理論名＋出典を3行程度で出す
- 自前サイト: 各記事の `theory` を本文中に明示し、記事末に出典を置く
- ただし**論文の権威で押さない**。「◯◯という研究があります。ただし限定もあります」という書き方を守る（[[writing_voice_v1]]）

### 2. 記事の問いを変える

「困りごとの対処」だけでなく、**上流の問い**を扱う連載を立てる。

- 「どんな子に育ってほしいか」を言葉にする回（自律／安心／好奇心 などを理論の言葉で並べる）
- 「そのために、自分はどう関わるか」を**タイプ別**に分けて書く回
- 困りごとの記事は入口として残す（検索から来る人の受け皿）

### 3. 相談パートナーとしての形

**個別相談は受けない**（週3時間と両立しない・不可逆な負荷）。代わりに次の形で「相談されている感じ」を作る。

- **診断の自由記述（worry）に、記事で答える**。実際に届いた言葉を起点に書く（データが貯まり次第）
- **「相談室」形式の連載**: 匿名の相談文 → 理論で整理 → タイプ別の関わり方、の3部構成
- note のコメント返信を続ける（いま未返信ゼロを維持）
- [[soudan]]（`web/soudan/`）の公的相談先ページは、**こちらが抱え込まない**ための装置として維持する

### 4. 名乗りを変える

プロフィール文・サイトのトップで、**「学術」と「一緒に考える」を明示する**。
「寄り添う」「共感」だけでは、市場の他の発信者と区別がつかない。

#### プロフィール改訂案（オーナーが貼り替え・各3分）

**note**
```
子育ての考え方を、親のことばに。
教育学・発達心理の研究をもとに、「どんな子に育てたいか」「自分はどう関わるか」を一緒に考えるメディアです。
正解は出しません。選べる形にしてお渡しします。
▼8つのこそだちタイプ診断（3分）
```

**Instagram / Threads（150字以内）**
```
0〜6歳の子と過ごす人へ
教育学・発達心理の研究をもとに、関わり方を一緒に考えるメディア
「◯歳までに」は言いません
▼こそだちタイプ診断（3分）
↓リンクから
```

### 5. 商品の位置づけ

- **¥100 相性記事**: 「わが家の組み合わせ」＝パートナーとの関わり方の整理。相談パートナーの入口として整合。
- **¥300 タイプ別**: 「あなたのタイプの、もう少し細かい話」＝理論の深掘り。**出典を見せる方針と最も相性がよい**。
- 将来の候補: 「どんな子に育てたいか」を整理するワーク（PDF）。個別相談の代替として機能する。

## 守る線（変えない）

- **断定しない。親を責めない。「◯歳までに」「差がつく」を書かない。**
- **研究の限定を一緒に書く**（効果があるとだけ書かない）。学術で戦うとは、都合のいい研究を引くことではない。
- **医療・発達の判断はしない**。相談先を必ず置く。
- 実体験を装わない。書けないことは書かない。
