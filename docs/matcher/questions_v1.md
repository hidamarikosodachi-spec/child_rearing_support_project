# 診断「わが家のこそだちタイプ」 質問セット v1（確定版・計18問）

> 実装の正本。サイト側（`web/matcher/questions.js`）はこのファイルから起こす。変更時は必ず両方を更新する。
> 設計方針は [[type_system_v1]] §4。v0（12問・6軸）からの変更＝**3軸に絞り各軸5問**。
> Q1〜Q6 は [[questions_v0]] から**文言そのまま流用**（検証済の表現）。Q7 以降が v1 新規。

## 表現の原則（v0 から継承・厳守）

1. **「正解」を匂わせない**（「子のためにベストは？」と聞かない）
2. **両極を等しく丁寧に**（片方だけ短い・投げやりにしない）
3. **行動を聞く、信念を聞かない**（「〜だと思う」ではなく「〜しがち」）
4. **罪悪感トリガーを避ける**（「叱り方」「泣かせ方」など直接的な負荷ワードを使わない）
5. どの選択肢も**実在する子育ての形**として書く（一方を消極的に描かない）

## 回答形式

5段階：**Aに近い / ややA / どちらとも / ややB / Bに近い** → スコア `-2, -1, 0, +1, +2`
軸スコア＝その軸5問の平均（−2.00〜+2.00）。極性は `>0` を+極、`<0` を−極、**|平均| < 0.4 は「まんなか」**として近接タイプを併記（[[type_system_v1]] §4）。

## A. 主導権 I（導く I+ ⇔ 委ねる I−）5問

### Q1（v0-Q5 流用）休日の過ごし方
**休日の午前中、子どもとの過ごし方として近いのは？**
- A: 「今日は○○しよう」と親が提案して一緒にやる
- B: 「何したい？」と聞いて、子が選んだことに付き合う

→ A ほど I+

### Q2（v0-Q6 流用）学び・教材選び
**絵本・知育教材・習い事を選ぶとき、近いのは？**
- A: 親が「これがいい」と思うものを用意・提案する
- B: 子が「これがいい」と興味を示したものから選ぶ

→ A ほど I+

### Q3（新規）遊びの途中
**子どもが積み木で遊んでいます。あなたは近くにいます。**
- A: 「こうすると高くなるよ」と、やり方を見せたり一緒に作ったりする
- B: 子どもがやっていることを、口を出さずに眺めている

→ A ほど I+

### Q4（新規）はじめての場所
**公園や児童館で、子どもが他の子の輪に入れずにいます。**
- A: 「一緒に行ってみようか」と声をかけて、輪に入るきっかけを作る
- B: 子どもが自分から動くまで、隣で待つ

→ A ほど I+

### Q5（新規）一日の終わり
**寝る前のひととき、どちらに近いですか？**
- A: 「今日はこれをしよう」と決めていることがある（絵本・振り返りなど）
- B: その日の流れにまかせて、子どもがしたいことをする

→ A ほど I+

## B. 構造性 S（整える S+ ⇔ 流れる S−）5問

### Q6（v0-Q3 流用）生活リズム
**平日の生活リズム（食事・お風呂・寝る時間）について、あなたの家はどちらに近いですか？**
- A: だいたい毎日決まった時間に動く。崩れると落ち着かない
- B: その日その日で柔軟に動く。多少ずれても気にならない

→ A ほど S+

### Q7（v0-Q4 流用）予定変更
**「今日はこの後○○しよう」と決めていたのに、子どもが「別のことやりたい」と言い出しました。**
- A: 基本は予定を優先する。「あとでね」と話す
- B: 子どもがやりたいことに切り替えることが多い

→ A ほど S+

### Q8（新規）おもちゃの片づけ
**おもちゃの置き場所について、近いのは？**
- A: 置き場所を決めていて、だいたいそこに戻るようにしている
- B: 遊び方に合わせて動くので、置き場所はその時々で変わる

→ A ほど S+

### Q9（新規）お出かけの準備
**家族で出かける日、あなたは…**
- A: 行き先や時間をある程度決めてから出る
- B: とりあえず出て、その場で決めることが多い

→ A ほど S+

### Q10（新規）できごとへの向き合い方
**予定が崩れた日（寝坊した、雨で中止になった）、あなたの気持ちに近いのは？**
- A: 立て直したくなる。次の予定に間に合わせようと動く
- B: 「今日はこういう日」と受け入れて、流れを変える

→ A ほど S+

## C. 応答性 R（寄り添う R+ ⇔ 見守る R−）5問

### Q11（v0-Q1 流用）ぐずぐずへの反応
**子どもが理由のはっきりしない不機嫌・ぐずぐずを始めました。あなたの最初の反応は、どちらに近いですか？**
- A: すぐ近くに行って抱きしめたり、「どうした？」と声をかけたりする
- B: まず少し距離を保って、自分で気持ちを立て直すのを待つ

→ A ほど R+

### Q12（v0-Q2 流用）先回り vs 待ち
**子どもが工作や着替えで困っているそぶりを見せています。声をかけられる前に、あなたは…**
- A: 「手伝おうか？」と先に声をかけることが多い
- B: 子どもが「手伝って」と言うまで待つことが多い

→ A ほど R+

### Q13（新規）転んだとき
**子どもが転びました。大きなけがではなさそうです。**
- A: すぐ駆け寄って抱き起こし、「痛かったね」と声をかける
- B: 少し様子を見て、自分で立ち上がるかどうかを待つ

→ A ほど R+

### Q14（新規）小さなサイン
**子どもが何か言いたそうにしているけれど、言葉になっていません。**
- A: 「○○したいの？」と、こちらから気持ちを言葉にしてみる
- B: 言葉が出てくるまで、急かさずに待つ

→ A ほど R+

### Q15（新規）ひとりの時間
**子どもがひとりで黙々と何かしている時間について、近いのは？**
- A: ときどき声をかけたり、様子を見に行ったりする
- B: そっとしておく。声はかけない

→ A ほど R+

## D. 文脈質問（3問・軸スコアには影響しない）

### CQ1: お子さんの年齢（複数選択可・必須）
0歳 / 1歳 / 2歳 / 3歳 / 4歳 / 5歳 / 6歳 / 7歳以上 / 妊娠中

→ 結果文の年齢適合（例：0-1歳にピクラー、4-6歳に就学の話）

### CQ2: きょうだい（単一選択・必須）
ひとり / 2人 / 3人以上 / これから

→ 結果文の「きょうだいのいる日の話」の出し分け

### CQ3: いま、いちばん気になっていること（自由記述・**任意**・200字まで）
**「いま、子育てでいちばん気になっていることを、よかったら一言だけ教えてください。（書かなくても結果は出ます）」**

→ **本診断で最も価値のあるデータ**。記事テーマ選定の一次情報（[[type_system_v1]] §5）。
→ 個人情報が書かれる可能性があるため、**原文は公開しない**（頻出語・要約のみ扱う）。

## 出題順（離脱を減らす設計）

1. **CQ1 → CQ2**（軽い属性から。ここで離脱する人は少ない）
2. **Q11 → Q15（応答性）** … 最も身近で答えやすい場面から始める
3. **Q6 → Q10（構造性）** … 生活実感。中盤で淡々と
4. **Q1 → Q5（主導権）** … 価値観に近く重いので後半
5. **CQ3（自由記述・任意）** … 最後。ここまで来た人は書いてくれる

> v0 は「価値観→具体」の順だったが、v1 では**離脱率の最小化**を優先し「答えやすい順」に変更した。
> 実際の離脱ポイントは保存データ（`drop_at`）で検証し、v2 で並べ替える。

## 実装メモ

- 1画面1問・進捗バー表示・戻れる。回答は `localStorage` に保持（リロードで消えない）。
- **未回答のまま次へ進めない**が、CQ3 だけはスキップ可。
- 所要の目安「3分」を開始画面に明記する。
