# 文章の作り方 v1 — 「AIっぽさ」をなくす

> オーナー指摘（2026-09-29）「Threads や IG の文章が読みにくく、AI 過ぎる。人が書いたような、
> 直感的にわかりやすい文章ではない」。実投稿を読み直して原因を特定し、ルール化した。

## 何がAIっぽかったか（実投稿の分析）

| 癖 | 実例（9/30 旧版） |
|---|---|
| 全文が同じ長さ・1文1段落で均一 | 6文すべてがほぼ同じ長さ |
| 毎回きれいにオチがつく | 「〜だけ言って出た」→「短くなったと言われた」＝必ず解決 |
| 毎回、問いかけで終わる | 「どんなふうに別れていますか？」 |
| 具体が「一般化された具体」 | 「保育園の玄関」「先生」止まり |
| 感情を説明している | 「泣かせて出てくる自分がつらい」 |

**根本原因**: 「誰にでも当てはまる」ように書くと、具体が抜けて生活が消え、**教材**になる。
読み手は内容より先に「人が書いたか」を感じ取る。教材に見えた時点で読まれない。

## ルール

1. **固有の細部を最低2つ**（時刻・モノ・実際のセリフ・音・体の動き）
   × 玄関で泣く → ○ 靴を脱がせている途中で、もう泣き始める
2. **問いかけで終わるのは3投稿に1回まで**。基本は言い切る。
3. **オチをつけない投稿を混ぜる**。解決しないまま終わってよい。
4. **文の長短を混ぜる**。短い断片のあとに、少し長い一文。
5. **セリフはそのまま**（「」で子ども・先生・パートナーの言葉）
6. **感情語を名指ししない**。× つらい → ○ 泣き声はドアの外まで聞こえた
7. **役割名を減らす**（ママは／パパは → 自分／この子）
8. **「〜気がする」「〜と思う」の締めは1投稿1回まで**

## 構成のルール（オーナー指摘 2026-09-29 追加）

> 指摘：「内容ではなく**文章の構成・作り**。10/4 の投稿は『た。』で終わりすぎている。
> 小説・物語・ドラマのような表現が読んでいて面白い。**親の感情と子の感情が入る**ようにできないか」

### ① 語尾を単調にしない
同じ語尾が3つ続いたら書き直す。使える終わり方を混ぜる。

| 型 | 例 |
|---|---|
| 過去 | 積み木を積んでいた。 |
| 現在・進行 | 黙って箱に戻している。 |
| 断定 | 違いはたぶん、座っていたことだけだ。 |
| 体言止め | 朝7時40分、保育園の玄関。 |
| セリフ止め | 「ママ、見て」 |
| 心内語（——で始める） | ——あぁ、また見てなかった。 |

### ② 場面から始める（説明から始めない）
× 「気づくと言い方がきつくなっている」（要約から入る）
○ 「夕方の台所で、その3つを全部言った」（場面に入る）

### ③ 時間を流す — 小説の順番で書く
**日常 → ずれ（気づき）→ 余韻**。起きたことを順番どおりに置き、結論を先に言わない。

### ④ 親の感情と、子の感情を**両方**入れる ← いちばん大事
- **子**は「表情・体・動作」で書く（感情語を使わない）
  例：崩れた積み木を、ひとつずつ、黙って箱に戻している／腕の中で体をねじって、こちらに手を伸ばしている／着替えを持ったまま固まって、何か言いかけて、やめた
- **親**は「心内語」で書く（——で始める1行）
  例：——あぁ、また見てなかった。／——あ、いまの言い方。

この2つが揃うと、読み手は「場面を見ている」状態になる。片方だけだと説明文に戻る。

### ⑤ 終わり方は「余韻」だが、**感情は素直に名指しする**（2026-09-29 オーナー修正）

当初は「感情語を使わず映像の余韻で置く」としたが、オーナーの修正で方針を改めた。
**わかりにくい詩的な余韻より、直感的に伝わることを優先する。**

| | |
|---|---|
| × 説明で回収する | 「自分の残量の問題なんだと思うようになった」 |
| △ 映像に寄せすぎ | 「分かっているのに、あの背中が消えてくれない」（何が言いたいか一拍考えさせる） |
| ○ **採用** | 「分かっているのに、**後悔**が消えてくれない」 |

途中は描写、**最後の一行だけは感情を名指ししてよい**。

### ⑥ 時制で「気づいたら」を出す（オーナー修正）

無意識のうちに起きたことは、**過去完了ぎみに書く**と後悔がにじむ。

| | |
|---|---|
| × | そのまま画面がSNSに切り替わる。 |
| ○ | そのまま画面がSNSに**切り替わっていた**。 |
| × | 塔はもう崩れていた。 |
| ○ | 積み木の塔はもう**崩れた後だった**。 |

**主語を省きすぎない**（「塔」→「積み木の塔」）。読み手が場面を一度で掴めることを優先する。

## Before / After（9/30 の投稿）

**Before**
> 保育園の玄関で、毎朝泣く。／先生に渡した瞬間の顔が、仕事中も頭から離れない。／
> 「すぐ泣きやみますよ」と言われて、それは分かっているけど、泣かせて出てくる自分がつらい。／
> ある朝、「バイバイ」を長引かせるのをやめて、「迎えに来るね」だけ言って出た。／
> 泣く時間は、少し短くなったと先生に言われた。／自分のほうが、まだ慣れていない。／
> 送りのとき、どんなふうに別れていますか？

**After（v1・細部は増えたが、まだ「た。」が続き説明的）**
> 朝、保育園の玄関。靴を脱がせている途中で、もう泣き始める。／先生に抱っこで渡して、ドアが閉まる。……

**After（v2・構成ルール適用＝これを標準とする）**
> 朝7時40分、保育園の玄関。
>
> 靴を脱がせようとしゃがんだところで、もう「やだ」が始まる。
>
> 先生が来て、抱っこで受け取ってくれる。腕の中で体をねじって、こちらに手を伸ばしている。
>
> ドアが閉まる。
>
> 「すぐ泣きやみますよ」。その言葉は本当だと思う。迎えに行けば、笑って走ってくるのだから。
>
> それでも電車の中で、あの伸ばした手を思い出している。
>
> ——慣れていないのは、たぶん自分のほうだ。

**変えたところ**: 時刻を入れて場面から始める／子の感情を体の動きで書く（体をねじる・手を伸ばす）／
「ドアが閉まる。」の一行で時間を切る／最後を心内語（——）にして説明で回収しない／語尾を た・る・だ で散らす。

## いちばん効く改善（オーナー判断待ち）

**実体験のメモを週1で3つもらう**（各2〜3行・5分）。

いま私は体験を持たないまま書いているので、どうしても「一般化された具体」になる。
実際にあった細部（言われた言葉・時間・場所・そのときの手の動き）が1つあるだけで、生っぽさが変わる。

メモの形式はなんでもよい。例:
- 「今朝、上の子が自分の長靴を下の子に履かせようとしてた。サイズが全然違うのに」
- 「夕方、何回言っても着替えなくて、結局こっちが黙って手を出した。無言だった」
- 「風呂で急に『ママの匂い好き』と言われた。前後の脈絡なし」

これを渡してもらえれば、**私が投稿・記事に仕立てる**。書くのは私。集めるのはオーナー。
