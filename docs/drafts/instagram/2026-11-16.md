# 研究カード③ 聞こえていただけの言葉は、2歳の語彙と関連しなかった

## キャプション（投稿本文）

2013年に、アメリカの研究チームが発表した研究です（Weisleder と Fernald・Psychological Science）。家での親子の言葉を1日じゅう録音し、子どもに向けた言葉と、周りで聞こえていただけの言葉を分けて調べています。

分かったこと
・子どもに向けて話された言葉が多い子は、言葉を聞き取る速さが育っていました。
・向けて話された言葉が多い子は、24か月のときの語彙が大きい結果でした。
・周りで聞こえていただけの言葉は、語彙と関連が見られませんでした。

分かっていないこと
対象は、スペイン語を話す収入の低い家庭です。日本の家庭に当てはまるとは限りません。関連を見た研究で、「向けて話せば必ず語彙が伸びる」と示したものではありません。家庭の事情が結果に影響した可能性もあります。

今日試すなら、子どもに話しかけるとき、顔を見る。研究が示した方法ではなく、読み方のひとつです。

気になることがあるときは、小児科・保健センター・子育て支援センターで相談できます。
