## 2. この半年で何を作るか

**結論: 半年の目標は「月の売上」ではなく、売れる状態をつくること。**
具体的には **読者500人・月間PV3,000・診断回答200件**。ここに乗って初めて、課金が意味のある数字になる。

半年後（2027年3月）の目標値：

| 指標 | 現在 | 2027年3月 |
|---|---|---|
| note フォロワー | 3 | **80** |
| 月間PV（note＋自前サイト） | 約300 | **3,000** |
| 診断の累計回答 | 0 | **200** |
| 有料記事の累計販売 | 0 | **30件（約6,000円）** |
| 月あたり売上 | 0円 | **2,000〜5,000円** |

正直に書くと、**半年では生活費にならない**。狙っているのは、検索順位・読者・診断データという**あとから効く資産**で、売上はその副産物として立ち上がり始める段階にある。

## 3. 四半期の組み立て

### Q1：10月 — 入口を直す（いま実行中）

**仮説**: 表示されているのに読まれないのは、タイトルが社内用語（「◯◯タイプ」）になっているから。

- 8タイプ記事の完走（10/13）
- 公開済み記事のタイトル修正・冒頭に診断導線 ✅ 実施済
- 3問の簡易診断 ✅ 公開済（18問は初見には重い）
- 自前サイトを毎日更新（予約公開＋自動デプロイ）✅ 稼働
- note 誠実接触 週3バッチ

**判定（10/24）**: 診断回答 10件・note フォロワー 10人。
**未達なら**: 診断を看板から下ろし、記事単体の読まれ方に資源を寄せる。

### Q2：11〜12月 — はじめての課金と、検索の立ち上がり

- **商品A ¥100「わが家の組み合わせ」**（全36通りの相性・11月上旬）
  役目は売上ではなく「**買う人が実在するか**」の確認。相手にも診断させる動機になり、回答データが増える副作用がある。
- **商品B ¥300「◯◯タイプのもう少し細かい話」**（タイプ別・まず2本・11月下旬）
- 自前サイトの検索記事を**90本**まで（毎日1本）
- Search Console の検索クエリから次のテーマを決める（推測で書かない）

**判定（12/26）**: 月間PV 1,000・フォロワー 30人・有料販売 5件。
**未達なら**: web 集客そのものを再決裁する（別チャネルか、一次情報の取り直し）。

### Q3：1〜3月 — 資産を広げる

- 検索流入が立っていれば、**アフィリエイトの仕組みだけ入れる**（「遊びと道具」カテゴリ・広告表記必須・**月間PV1,000が着手条件**）
- 診断データ（200件）から**実際の悩みの分布**を出し、そこへ記事と商品を寄せる
- **デジタル商品**の検討（親向けガイドPDF／タイプ別ワーク）。物理製品は作らない

**判定（3月末）**: 月の売上 2,000〜5,000円・PV 3,000。

## 4. 収益の3本柱と、その順番

1. **有料記事（いま着手）** — ¥100 → ¥300 の階段。原価ゼロ・在庫なし・即日公開できる。最初の1件が出る確率を最大化する設計。
2. **アフィリエイト（PV1,000到達後）** — 料率2〜3%で、月1万円には月間PV1万が要る。**収益源としては期待しない**。読者が「結局どれを買えばいいか」に答えるための機能として入れる。
3. **デジタル商品（2027年以降）** — 診断とPDFパイプラインという既存資産から作れる。乳幼児向けの**物理製品は作らない**（PL責任・在庫・返品が週3hと両立しない）。

## 5. 制約と、やらないこと

**制約**
- オーナーの可処分時間：**週3時間**。これを超える計画は立てない。
- Claude はセッションが開いている時しか動けない。時刻を約束する運用にしない。
- 販売・配信物のオーナー目視と、不可逆な施策のGOは不変。

**やらないこと（意図的に）**
- X の運用強化／Threads の増量（到達はあるが人が残らないため）
- note 創作大賞（応募34万件・長編向き・週3hと両立しない）
- 物理製品／オフライン展開（知人・地域ネットワークが無いことが判明済）
- 広告出稿（投じる前に、転換が成立していない）

## 6. 撤退・方向転換の線

- **12月末に月間PV1,000とフォロワー30が未達** → web 集客を再決裁する
- **診断回答が10月末に10件未満** → 診断を看板から下ろす
- **オーナーが週3hを超えて消耗している** → 本数を落とす（燃え尽きは不可逆）
