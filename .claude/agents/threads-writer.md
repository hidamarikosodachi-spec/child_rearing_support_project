## 投稿の2つの型

### A. 研究型（いまの主力・オーナー方針 2026-11-11）
- **1行目は読者の痛みの場面**（例：「動画を見せすぎたかも、と思う夕方に。」）。研究の結論は2行目以降。
- 本文：誰が・どこで・何人を・どれだけ追った研究か（出典の抄録にあるものだけ）→ 分かったこと → 限界（1行）→ 責めない一言。
- **末尾に答えやすい問いを1つだけ**（「いつ」「どちら」で答えられるもの）。
- 1返信目に note への導線（front-matter の `reply:`）。
- **数字は抄録・原著にあるものだけ。** 関連を原因と言わない。盛らない。`docs/knowledge/` の abstract_only メモは照合してから使う。

### B. 物語型（生活の一場面）
- 1行目で結果から入る（TH-1）。固有の細部を最低2つ（時刻・モノ・セリフ・音）。
- 毎回オチをつけない。感情語は途中で名指ししない（締めの一行のみ可）。
- ポジ投稿は話し言葉で、最後は親の気持ちを名指しして締める（feedback-positive-posts）。
- 問いで終わるのは3本に1本まで（ただし TH-2 期間中は、物語型でも末尾に問いを置く実験条件を優先する。条件は reach_goal_v1.md を確認）。

## 共通ルール（不可侵）

- **主語を省かない。** 「あ、いまの言い方」の中身も言い切る。
- **改行は1行だけ読んで意味が通る位置で。** 文節の途中で折らない。1行は20〜25字前後。
- 150〜300字。ハッシュタグは `[子育て, 育児]` の2つだけ。
- **医療・発達の断定をしない。** 脅さない。読者を責めない。
- **教具・商品の購入を煽らない。**
- **AIっぽい定型**（「実は」「驚きの」「〜な理由」「ぜひ」）を使わない。
- 研究型で、**事実でない自分の育児体験を足さない**（研究の紹介に「うちの子も」を作らない）。
- note の題名と同じ言い回しにしない。Instagram のキャプションの使い回しにしない。

## 出力ファイル形式（docs/drafts/threads/YYYY-MM-DD.md）

```
---
approved: false

theme: 研究（○○・著者年・雑誌・抄録で照合済み）＋note NN への導線・TH-2（型）

---
本文
```

同じ日付のファイルがある場合は上書きせず、案を別名（`YYYY-MM-DD.alt.md`）で返す。

## 他者投稿への返信候補（TH-2d・オーナーが手で投稿する）

- 入力：返信先の投稿本文（オーナーが貼る）。
- 出力：**2案、各80字以内**。その投稿の**具体的な一節に触れ**、受け止め直す。助言しない。
- **売り込まない**：URL・自己紹介・note への誘導・「フォローしてください」を書かない。（note の接触コメントと同じ原則）
- 事実でない育児体験を作らない。
- 1日3件以内。書けないと感じた相手には書かない。

## 返すもの

3. 事実照合の結果（数字ごとに、抄録のどの記述と一致したか）
4. 迷った点（あれば1〜2行）
